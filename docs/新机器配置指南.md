# 新机器配置指南（从零开始）

适用于本仓库的硬件：CoreXY + 三 Z 丝杆（Trident 式）、TGL 主板（STM32F446，CAN）、TGL36V3 工具头 CAN 板、小螃蟹涡流探针（LDC1612）。多热端机型还有 multihotend 扩展板（STM32F072，USB）和 CxChanger 换头机构。

每完成一步再进行下一步。带 ⚠️ 的步骤不要跳过。

---

## 第 0 步：准备上位机软件

1. 上位机（树莓派等）装好 Klipper、Moonraker、Mainsail 或 Fluidd（推荐用 KIAUH 一键安装）。
2. 配置 CAN 网络 `can0`，波特率与固件一致（常用 1000000）。
3. 给主板、工具头板、多热端扩展板刷好 Klipper 固件（CAN 板用 CAN 或 CAN 桥接固件，扩展板用 USB 固件）。
4. ⚠️ 涡流探针需要修改 Klipper 源码 `~/klipper/klippy/extras/ldc1612.py`（小螃蟹涡流扫床教程第二节；本机实测三处都要改，tap 才能稳定）：

   | 位置 | 原值 | 改为 |
   |---|---|---|
   | `SETTLETIME` | `0.005` | `0.0002` |
   | `self.set_reg(REG_ERROR_CONFIG, ...)` | `(0x1f << 11) \| 1` | `(0x1c << 11) \| 1` |
   | `self.data_rate` | `400` | `250`（工具头板是 STM32F072，400 次/秒负担过重） |

   `data_rate` 改成 250 后 tap 需要 SciPy，否则启动报 `DigitalFilter require the SciPy module`：
   ```bash
   ~/klippy-env/bin/pip install scipy -i https://pypi.tuna.tsinghua.edu.cn/simple
   sudo systemctl restart klipper        # 改 .py 后必须重启服务，FIRMWARE_RESTART 不会重新加载
   grep -n "SETTLETIME\|REG_ERROR_CONFIG\|data_rate" ~/klipper/klippy/extras/ldc1612.py
   ```
   以后更新 Klipper 时这些修改可能被覆盖，更新后用最后一条命令检查。
5. **仅多热端**：
   - 安装 klipper-multitool-stats 插件（提供 `[multitool]`）
   - 安装涡流对刀插件 tool_eddy_calibration（提供 `[tool_eddy_calibration]`）：把 `tool_eddy_calibration.py` 放到 `~/klipper/klippy/extras/` 后重启 Klipper。源码 https://github.com/chengxg/tool_eddy_calibration ，教程 https://demo.chengxg.top/pangxie/articles/eddy-calibration/

## 第 1 步：部署配置

⚠️ `modules/` 目录必须和 `printer.cfg`、`profile_*.cfg` 放在同一层，也就是 `~/printer_data/config/modules/`。机型清单里的 `modules/...` 路径是相对于清单文件所在目录的，放错位置会报 `Include file '.../modules/core/mainboard.cfg' does not exist`。

部署后的目录应该是这样：
```
~/printer_data/config/
├── printer.cfg
├── profile_singletool.cfg
├── profile_multitool.cfg
├── moonraker.conf
├── myvariables.cfg
└── modules/
    ├── core/mainboard.cfg ...
    └── ...
```

**方式一：在打印机上用 git（推荐）**
```bash
cd ~
git clone <本仓库地址> printer-config          # 已经 clone 过就 cd ~/printer-config && git pull
cp -r ~/printer_data/config ~/printer_data/config.bak.$(date +%Y%m%d%H%M)   # 备份原有配置
cp -r ~/printer-config/config/. ~/printer_data/config/
ls ~/printer_data/config/modules/core/        # 应该看到 mainboard.cfg 等 4 个文件
```
注意源路径是 `config/.`（末尾有个点）：复制的是目录里的内容，不会多套一层 `config/`。

**方式二：从 Windows 用 scp 上传**（PowerShell，`<打印机IP>` 换成实际地址）
```powershell
scp -r D:\路径\到\仓库\config\* klipper@<打印机IP>:/home/klipper/printer_data/config/
```

**不要用 Mainsail / Fluidd 网页上传**：网页只能上传文件，不会上传 `modules/` 文件夹。

部署完检查一下：
```bash
ls -la ~/printer_data/config/ ~/printer_data/config/modules/core/
```
文件属主应该是 `klipper`。如果是用 `sudo` 复制的，属主会变成 `root`，klipper 读不了，要执行 `sudo chown -R klipper:klipper ~/printer_data/config`。

部署后别忘了把原来 `printer.cfg` 末尾的 SAVE_CONFIG 数据块（在刚才的备份里）粘到新 `printer.cfg` 的最底部；新机器则按第 3 步清空。

## 第 2 步：选择机型、增减模块

1. 打开 `printer.cfg`，二选一：
   ```
   [include profile_singletool.cfg]      # 单热端
   # [include profile_multitool.cfg]     # 多热端
   ```
2. 打开对应的机型清单（`profile_singletool.cfg` 或 `profile_multitool.cfg`），按实际硬件增减模块：
   - 没有涡流探针：注释掉 `probe/eddy_tgl36v3.cfg`，启用 `probe/z_endstop_switch.cfg`
   - 暂时不用调平或网床：注释掉 `leveling/` 下对应的行
   - 规则详见 `config/README.md`
3. 如果只是先把机器动起来（XYZ 移动、调平、打印头），可以先用单文件调试配置 `debug/printer.cfg`，见文末「单文件调试配置」。

## 第 3 步：⚠️ 清空旧机器的校准数据

`printer.cfg` 最底部的 SAVE_CONFIG 数据是**旧机器**的涡流校准结果，新机器不能用。

保留 `# 小螃蟹Z涡流调平(配置要添加到根目录的printer.cfg,否则不生效)` 这一行注释，把它下面从 `#*# <---------------------- SAVE_CONFIG ---------------------->` 开始到文件末尾的全部内容删除。后面校准完 `SAVE_CONFIG` 时，Klipper 会自动在最底部重新生成。

## 第 4 步：填写各块板子的 ID

```bash
~/klippy-env/bin/python ~/klipper/scripts/canbus_query.py can0   # 查 CAN 设备的 UUID
ls /dev/serial/by-id/                                            # 查 USB 设备的串口
```

| 板子 | 文件 | 要改的项 |
|---|---|---|
| 主板 | `modules/core/mainboard.cfg` | `[mcu]` 的 `canbus_uuid` |
| 工具头 | `modules/toolhead/tgl36v3.cfg` | `[mcu toolhead]` 的 `canbus_uuid` |
| 多热端扩展板 | `modules/multitool/multihotend.cfg` | `[mcu multihotend]` 的 `serial` |

## 第 5 步：⚠️ 首次上电前的安全设置

当前配置里有几处调试时放宽的设置，新机器首次上电前要改回来：

1. **热端温度保护**
   - `modules/multitool/multihotend.cfg` 里 T0..T7 每个热端都是 `max_temp: 9999`、`min_temp: -210`，相当于关闭了过热和热敏断线保护。改为 `max_temp: 300`（按热端实际上限）、`min_temp: 0`。没装的热端把对应的 `[extruderN]` 和停靠坞风扇段注释掉，不要靠放宽温度范围绕过报错。
   - `modules/extruder/tgl36v3_single.cfg` 里 `min_extrude_temp:-119` 允许冷挤出，改为 `170`；`min_temp:-120` 改为 `0`。
2. **开机自动标记已归零**
   - `modules/core/common.cfg` 里的 `[delayed_gcode KINEMATIC_POSITION]` 会在开机后执行 `SET_KINEMATIC_POSITION`，不归零也能移动，坐标是错的，新机器上容易撞机。调试期间把这一段整段注释掉。
3. **多头热端数量**：把插件设置 `[multitool] tool_count`、热端定义的个数（`[extruder]`..`[extruderN]` 及对应停靠坞风扇）、对刀校准里的 `_TOOL_CALIB_VARS variable_tool_count` 统一成实际热端数量，多余的 `[extruderN]` 段和对应风扇段注释掉。

## 第 6 步：首次启动

在网页控制台执行 `FIRMWARE_RESTART`，确认没有报错、所有 MCU 都已连接。有报错先按提示修好配置。

## 第 7 步：基础检查（不要归零，不要加热）

1. **温度读数**：所有热端、热床、板载温度都显示室温附近（约 15～35°C）。显示 -200 多度或几百度说明热敏没接好或类型不对。
2. **限位**：执行 `QUERY_ENDSTOPS`，手动按下 X、Y 限位，状态应该从 `open` 变成 `TRIGGERED`。
3. **电机方向**：逐个执行下面的命令，观察电机是否先正转再反转：
   ```
   STEPPER_BUZZ STEPPER=stepper_x
   STEPPER_BUZZ STEPPER=stepper_y
   STEPPER_BUZZ STEPPER=stepper_z
   STEPPER_BUZZ STEPPER=stepper_z1
   STEPPER_BUZZ STEPPER=stepper_z2
   ```
   重点检查：**三个 Z 电机必须同向**（都先上升或都先下降），方向不对就在该电机的 `dir_pin` 前加上或去掉 `!`。
4. **驱动通讯**：执行 `DUMP_TMC STEPPER=stepper_z`（其它电机同理），能读出寄存器说明 UART 正常；报错说明 `uart_pin` 不对或驱动没装好。
5. **风扇**：用 `M106 S128` 测试模型风扇，`M107` 关闭。喉管风扇、停靠坞风扇在热端超过 50°C 时自动转，第 9 步加热时再检查。

**电机参数参考（本机）**

| 电机 | 电流 | 驱动模式 | 说明 |
|---|---|---|---|
| X / Y | 0.8A（保持 0.6A） | spreadCycle（`stealthchop_threshold: 0`） | 高速打印 |
| Z / Z1 / Z2 | 0.4A（保持 0.2A） | 静音（`stealthchop_threshold: 99999`） | 托起整个热床 |
| 挤出机 | 0.4A | 静音 | |

- `max_z_accel` 要 **200**（原 50）：涡流 tap 碰床后 0.15 秒内要抬起 ≥0.35mm，50 时会报 `insufficient lift`（详见 `docs/多头配置指南.md` 第五节 4.1 B）。改后注意 Z 轴有无异响、丢步。
- 调试时可以临时改电流、驱动模式，不用改配置，`FIRMWARE_RESTART` 后恢复：
  ```
  SET_TMC_CURRENT STEPPER=stepper_z CURRENT=0.6 HOLDCURRENT=0.4     ; 不要超过电机额定电流的约 80%
  SET_TMC_FIELD STEPPER=stepper_z FIELD=en_spreadcycle VALUE=1       ; 临时切 spreadCycle，VALUE=0 切回静音
  ```
  本机实测：tap 不稳定时切 spreadCycle 没有改善（噪声更大，需要更高阈值），最终是驱动修改和热机校准解决的。

## 第 8 步：XY 归零与行程

1. 把喷嘴手动移到打印区中间，执行 `G28 X`，再执行 `G28 Y`，手放在急停上。
   - 往反方向跑：CoreXY 的方向调整需要同时考虑两个电机，按 Klipper 文档调整 `stepper_x`/`stepper_y` 的 `dir_pin`。
2. 归零后用控制面板小步移动，确认 X 能走到 0～290、Y 能走到 0～300，不撞机械限位。不同时修改 `modules/core/mainboard.cfg` 里的 `position_max` 和 `position_endstop`。

## 第 9 步：热端、热床 PID 与风扇

配置里的热端 PID 是安装脚本给的**占位值**（多热端 `pid_kp: 26.213` 等），不校准温度会过冲、上下摆动。本机实测：目标 150°C 时在 155～157°C 来回跳，导致 `M109` 和一键对刀一直卡在"等温中"（多热端插件要求稳定在目标 ±1.5°C）。

```
M106 S0                                          ; 关模型风扇；喉管风扇会自动转，保持和使用时一致
PID_CALIBRATE HEATER=heater_bed TARGET=80
PID_CALIBRATE HEATER=extruder TARGET=150         ; 对刀 tap 用 150°C
PID_CALIBRATE HEATER=extruder1 TARGET=150        ; 多热端每个热端都要做
```

⚠️ **PID 写在被引用的模块文件里，不能用 `SAVE_CONFIG` 保存**（Klipper 不允许 SAVE_CONFIG 覆盖引用文件里的设置，会报 `... conflicts with included value`）。把控制台输出的 `pid_Kp`、`pid_Ki`、`pid_Kd` 手动填进对应文件，然后 `RESTART`：

| 加热器 | 文件 |
|---|---|
| 热床 `heater_bed` | `modules/core/heater_bed.cfg` |
| 单头 `extruder` | `modules/extruder/tgl36v3_single.cfg` |
| 多头 `extruder`、`extruder1`… | `modules/multitool/multihotend.cfg`（改第二个、带 `heater_pin: multihotend:T0H` 的 `[extruder]`） |

验证：`M109 S150`、`M190 S80`，温度应稳定在目标 ±1°C 以内。正常打印温度（如 220°C）可以再校准一次。

**温度保护与风扇检查**

- 热端 `min_temp: 0`、`max_temp: 300`（多头原配置是 -210 / 9999，等于关闭保护）；单头 `min_extrude_temp` 不要低于 170（原配置 -119 允许冷挤出）。
- 喉管风扇 `hotend_fan`（`modules/toolhead/tgl36v3.cfg`）多头时要监听所有热端：`heater: extruder, extruder1`，否则 T1 加热时不转。
- 停靠坞风扇：对应热端超过 50°C 时应启动；检查它的风会不会吹到工具头上的热端，吹到会让温度波动。

## 第 10 步：涡流探针校准（含 tap）

按小螃蟹涡流扫床教程（https://demo.chengxg.top/pangxie/articles/eddy-coil/ 第三节）。前提：第 0 步的 `ldc1612.py` 三处修改和 SciPy、第 7 步的 `max_z_accel: 200`、第 9 步的 PID 都已完成。

1. **加热并清洁喷嘴**（用涡流做 Z 限位时，校准要在热机条件下做）：
   ```
   M140 S80
   M109 S150
   M190 S80
   ```
   到温后擦干净喷嘴尖。
2. **驱动电流**（在喷嘴靠近热床约 2mm 处校准；配置里的 `reg_drive_current` 要保持注释，否则 SAVE_CONFIG 冲突）：
   ```
   G28
   LDC_CALIBRATE_DRIVE_CURRENT CHIP=eddy_probe
   SAVE_CONFIG
   ```
3. **高度曲线**（重启后重新加热到温）：
   ```
   PROBE_EDDY_CURRENT_CALIBRATE_AUTO
   ```
   垫 A4 纸，用 `TESTZ` 调到纸张抽动时有轻微阻力，`ACCEPT`；等控制台打印出噪声数据后**一定执行 `SAVE_CONFIG`**。
   本机参考（热机、250 次/秒）：驱动电流 24，噪声 0.001mm，MAD_Hz≈163。教程：MAD 到几百说明 Z 轴有问题。
4. **tap 阈值**（`tap_threshold` 在配置里保持注释，喷嘴在热床中间、离床 3～10mm）：
   ```
   G1 X150 Y150 Z5 F6000
   PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=guess
   PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=refine
   PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=verify
   SAVE_CONFIG
   ```
   本机结果：`tap_threshold: 64820.919`，verify 5 次极差 0.008mm。自动校准报阈值不对时，按教程用 `PROBE_ACCURACY METHOD=tap tap_threshold=40000` 手动找。
5. **验证**：
   ```
   G28
   PROBE_ACCURACY                       ; 非接触测量，标准差应在 0.005mm 以内
   G1 X150 Y150 Z5 F6000
   SET_Z_FROM_PROBE METHOD=tap          ; 连续执行 2～3 次，set_Z 应基本一致
   ```

⚠️ 重新校准高度曲线后 Z 基准会变，之后要重新调平、扫网床、调第一层。tap 调试的完整过程和排查记录见 `docs/多头配置指南.md` 第五节 4.1。

## 第 11 步：三点调平

1. 量出三根丝杆的实际中心坐标，填到 `modules/leveling/z_tilt.cfg` 的 `z_positions`。
2. ⚠️ **检查测点不能靠近热床边缘**（这是之前热床倾斜问题的根因，见 `docs/热床倾斜调试与修复记录.md`）：
   - `points` 填的是喷嘴坐标，探针实际位置要再加上 `y_offset`（20mm）。
   - 探针实际位置离热床边缘、螺丝、孔位至少 30mm。
   - 验证方法：在每个测点执行 `PROBE`，前后几个点的读数应该连续变化，不能突然跳变。
3. 执行调平：
   ```
   G28
   Z_TILT_ADJUST
   ```
   正常情况下几轮之内三点高差就小于 0.0075mm。如果出现 `Retries aborting: Probed points range is increasing`，检查 Z 电机方向和 `z_positions`。

## 第 12 步：网床与实测

```
G28
Z_TILT_ADJUST
G28 Z
BED_MESH_CALIBRATE
```
- 差值在 0.1～0.15mm 以内为正常。如果最后一排突然下降，就是边缘干扰，减小 `modules/leveling/bed_mesh.cfg` 里的 `mesh_max`。
- 用塞尺测试确认结果：执行 `PAPER_TEST_PREP`，再依次执行 `PAPER_TEST POINT=1` 到 `POINT=4`，4 个角的手感应该一致。
- 满意后执行 `SAVE_CONFIG` 保存网床。

## 第 13 步：共振补偿

```
G28
SHAPER_CALIBRATE
SAVE_CONFIG
```
看控制台输出里推荐的最大加速度，把 `modules/core/mainboard.cfg` 里 `[printer]` 的 `max_accel` 调到不超过这个值（当前是 10000）。

## 第 14 步：挤出与第一层

1. **挤出距离**：加热喷头，抽出 100mm 料，量实际挤出长度，按比例修正 `rotation_distance`：新值 = 旧值 × 实际长度 / 100。
2. **启用打印升温**：把 `modules/macros/print.cfg` 的 `PRINT_START` 里注释掉的热床和喷头升温恢复（删掉行首的 `# `）。
3. **切片软件开始 G-code**：`PRINT_START BED=[bed_temperature_initial_layer_single] EXTRUDER=[nozzle_temperature_initial_layer]`（变量名以所用的切片软件为准），并开启"标记对象"（Label objects）。
4. **第一层**：打一个单层方块，边打边微调 Z 偏移，满意后执行 `Z_OFFSET_APPLY_PROBE`、`SAVE_CONFIG`。
5. **压力提前、流量**：用切片软件自带的校准测试件确定。

## 第 15 步：多热端专项（仅多热端）

详细步骤、实测记录见 `docs/多头配置指南.md`，这里是顺序：

1. **配置修改**：切换多头机型、注释没装的热端、统一 `tool_count`、喉管风扇监听所有热端、Y 允许负值（停靠坞在热床前方）。
2. **停靠坞坐标**：手动把工具头移到每个停靠坞的位置，记下坐标，填到 `modules/multitool/changer_cxchanger.cfg` 的 `variable_tN_dock_x` / `variable_tN_dock_y`。同时检查 `dock_shift_x`、`dock_dodge_y`、`dock_safe_y`。
3. **低速试换头**：先把 `feed_safe` / `feed_fast` / `feed_slow` 调低，执行 `T0`、`UNTOOL`、`T1`、`T0`，确认抓取和放回动作正确后再恢复速度。
4. **每个热端做 PID**（第 9 步），否则对刀会卡在"等温中"。
5. **对刀线圈**：`TEST_LDC1612`（约 2.2MHz），量出 `coil_x/y/z`，`scan_height` 让喷嘴在线圈上方约 0.5mm；本机 `coil_x: 168.08`、`coil_y: 283.75`、`coil_z: 0.85`、`scan_height: 0.5`。
6. **一键对刀**（tap 已在第 10 步调通）：
   ```
   G28
   CALIBRATE_TOOL TOOL=0          ; 基准，必须先做
   CALIBRATE_TOOL TOOL=1          ; 两次之间不要 G28
   T1                             ; 输出"T1 加载校准值"即为偏移，插件换头时自动加载
   ```
   单个工具都没问题后，可以用 `CALIBRATE_ALL_TOOLS` 批量校准。结果保存在 `myvariables.cfg`。

## 常见问题速查

| 现象 | 先检查 |
|---|---|
| `Include file '.../modules/...' does not exist` | `modules/` 没上传（网页上传不传文件夹）；或者多套了一层 `config/config/`；或者文件属主是 root。见第 1 步 |
| 启动报 `Option 'xxx' is not valid` | 拔掉模块后残留了只属于它的设置，例如涡流的 SAVE_CONFIG 数据 |
| 网床呈单方向平面倾斜 | 是否先执行了 `Z_TILT_ADJUST`；调平测点是否靠近边缘（见调试记录） |
| 每次重启后第一次调平高差很大 | 正常，Z 电机断电后热床会移位，重启后要先调平再扫床 |
| `Move out of range` | 坐标超出行程；校准时探针偏移会让喷嘴移到更靠前的位置 |
| `DigitalFilter require the SciPy module`（停机） | `ldc1612.py` 的 `data_rate` 改了，需要安装 SciPy（第 0 步） |
| tap 报 `insufficient lift`，或 `insufficient slope delta`（负数） | `max_z_accel` 太小（第 7 步）；`ldc1612.py` 三处修改是否都做了（第 0 步） |
| tap 能检测到但结果分散（极差 >0.05mm） | `ldc1612.py` 的 `data_rate`（F072 工具头要 250）；热机、清洁喷嘴后重新校准涡流（第 10 步） |
| `Tap not configured` | 配置或 SAVE_CONFIG 里还没有 `tap_threshold`，先做第 10 步第 4 条 |
| `M109` / 对刀卡在"等温中" | 热端 PID 未校准，温度在目标附近摆动（第 9 步） |
| `SAVE_CONFIG ... conflicts with included value` | 要保存的参数（PID、`reg_drive_current` 等）写在被引用的模块文件里：PID 改为手动填写；`reg_drive_current` 在模块里注释掉 |
| 改了 `ldc1612.py` 不生效 | 要 `sudo systemctl restart klipper` 重启服务，`FIRMWARE_RESTART` 不会重新加载 Python 文件 |
| 打印中途 Klipper Shutdown | 在 `klippy.log` 中搜索 `Shutdown`，常见原因是 CAN 通讯超时或加热保护 |

## 单文件调试配置

`debug/printer.cfg` 是一份不引用任何其它文件的调试配置，只包含 XYZ 运动、涡流探针、三点调平、网床和简单的打印头，适合新机器先把运动和调平调通：

1. 复制为 `~/printer_data/config/printer.cfg`（先备份原文件），填写主板和工具头的 `canbus_uuid`。
2. 还没装或没接的硬件，把对应整段注释掉（文件里每段都标了【必需】或【可选】）。
3. 调试速度和加速度已经降低，注释里写了正式值。
4. 常用命令：`LEVEL_ALL`（归零 → 调平 → 重新 Z 归零 → 扫床）、`PAPER_TEST POINT=1~4`（塞尺测试）、`PROBE_EDDY_CURRENT_CALIBRATE_AUTO`（涡流首次校准）。
5. 调通后换回 `config/` 的正式模块化配置，把 SAVE_CONFIG 数据块搬到正式 `printer.cfg` 的最底部。
