# 新机器配置指南（从零开始）

适用于本仓库的硬件：CoreXY + 三 Z 丝杆（Trident 式）、TGL 主板（STM32F446，CAN）、TGL36V3 工具头 CAN 板、小螃蟹涡流探针（LDC1612）。多热端机型还有 multihotend 扩展板（STM32F072，USB）和 CxChanger 换头机构。

每完成一步再进行下一步。带 ⚠️ 的步骤不要跳过。

---

## 第 0 步：准备上位机软件

1. 上位机（树莓派等）装好 Klipper、Moonraker、Mainsail 或 Fluidd（推荐用 KIAUH 一键安装）。
2. 配置 CAN 网络 `can0`，波特率与固件一致（常用 1000000）。
3. 给主板、工具头板、多热端扩展板刷好 Klipper 固件（CAN 板用 CAN 或 CAN 桥接固件，扩展板用 USB 固件）。
4. 涡流探针需要修改 Klipper 源码（`modules/probe/eddy_tgl36v3.cfg` 开头的注释）：
   - `klippy/extras/ldc1612.py` 中，`self.set_reg(REG_ERROR_CONFIG, (0x1f << 11) | 1)` 的 `0x1f` 改为 `0x1c`
   - `SETTLETIME = 0.005` 改为 `0.0002`
5. **仅多热端**：
   - 安装 klipper-multitool-stats 插件（提供 `[multitool]`）
   - 安装 Simple-Multi-Hotend 涡流对刀插件（提供 `[tool_eddy_calibration]`）：https://github.com/cx330-TXY/Simple-Multi-Hotend

## 第 1 步：部署配置

⚠️ `modules/` 目录必须和 `printer.cfg`、`profile_*.cfg` 放在同一层，也就是 `~/printer_data/config/modules/`。机型清单里的 `modules/...` 路径是相对于清单文件所在目录的，放错位置会报 `Include file '.../modules/core/mainboard.cfg' does not exist`。

部署后的目录应该是这样：
```
~/printer_data/config/
├── printer.cfg
├── profile_singletool.cfg
├── profile_multitool.cfg
├── moonraker.conf
├── myvariables.cfg
└── modules/
    ├── core/mainboard.cfg ...
    └── ...
```

**方式一：在打印机上用 git（推荐）**
```bash
cd ~
git clone <本仓库地址> printer-config          # 已经 clone 过就 cd ~/printer-config && git pull
cp -r ~/printer_data/config ~/printer_data/config.bak.$(date +%Y%m%d%H%M)   # 备份原有配置
cp -r ~/printer-config/config/. ~/printer_data/config/
ls ~/printer_data/config/modules/core/        # 应该看到 mainboard.cfg 等 4 个文件
```
注意源路径是 `config/.`（末尾有个点）：复制的是目录里的内容，不会多套一层 `config/`。

**方式二：从 Windows 用 scp 上传**（PowerShell，`<打印机IP>` 换成实际地址）
```powershell
scp -r D:\路径\到\仓库\config\* klipper@<打印机IP>:/home/klipper/printer_data/config/
```

**不要用 Mainsail / Fluidd 网页上传**：网页只能上传文件，不会上传 `modules/` 文件夹。

部署完检查一下：
```bash
ls -la ~/printer_data/config/ ~/printer_data/config/modules/core/
```
文件属主应该是 `klipper`。如果是用 `sudo` 复制的，属主会变成 `root`，klipper 读不了，要执行 `sudo chown -R klipper:klipper ~/printer_data/config`。

部署后别忘了把原来 `printer.cfg` 末尾的 SAVE_CONFIG 数据块（在刚才的备份里）粘到新 `printer.cfg` 的最底部；新机器则按第 3 步清空。

## 第 2 步：选择机型、增减模块

1. 打开 `printer.cfg`，二选一：
   ```
   [include profile_singletool.cfg]      # 单热端
   # [include profile_multitool.cfg]     # 多热端
   ```
2. 打开对应的机型清单（`profile_singletool.cfg` 或 `profile_multitool.cfg`），按实际硬件增减模块：
   - 没有涡流探针：注释掉 `probe/eddy_tgl36v3.cfg`，启用 `probe/z_endstop_switch.cfg`
   - 暂时不用调平或网床：注释掉 `leveling/` 下对应的行
   - 规则详见 `config/README.md`
3. 如果只是先把机器动起来（XYZ 移动、调平、打印头），可以先用单文件调试配置 `debug/printer.cfg`，见文末「单文件调试配置」。

## 第 3 步：⚠️ 清空旧机器的校准数据

`printer.cfg` 最底部的 SAVE_CONFIG 数据是**旧机器**的涡流校准结果，新机器不能用。

保留 `# 小螃蟹Z涡流调平(配置要添加到根目录的printer.cfg,否则不生效)` 这一行注释，把它下面从 `#*# <---------------------- SAVE_CONFIG ---------------------->` 开始到文件末尾的全部内容删除。后面校准完 `SAVE_CONFIG` 时，Klipper 会自动在最底部重新生成。

## 第 4 步：填写各块板子的 ID

```bash
~/klippy-env/bin/python ~/klipper/scripts/canbus_query.py can0   # 查 CAN 设备的 UUID
ls /dev/serial/by-id/                                            # 查 USB 设备的串口
```

| 板子 | 文件 | 要改的项 |
|---|---|---|
| 主板 | `modules/core/mainboard.cfg` | `[mcu]` 的 `canbus_uuid` |
| 工具头 | `modules/toolhead/tgl36v3.cfg` | `[mcu toolhead]` 的 `canbus_uuid` |
| 多热端扩展板 | `modules/multitool/multihotend.cfg` | `[mcu multihotend]` 的 `serial` |

## 第 5 步：⚠️ 首次上电前的安全设置

当前配置里有几处调试时放宽的设置，新机器首次上电前要改回来：

1. **热端温度保护**
   - `modules/multitool/multihotend.cfg` 里 T0..T7 每个热端都是 `max_temp: 9999`、`min_temp: -210`，相当于关闭了过热和热敏断线保护。改为 `max_temp: 300`（按热端实际上限）、`min_temp: 0`。没装的热端把对应的 `[extruderN]` 和停靠坞风扇段注释掉，不要靠放宽温度范围绕过报错。
   - `modules/extruder/tgl36v3_single.cfg` 里 `min_extrude_temp:-119` 允许冷挤出，改为 `170`；`min_temp:-120` 改为 `0`。
2. **开机自动标记已归零**
   - `modules/core/common.cfg` 里的 `[delayed_gcode KINEMATIC_POSITION]` 会在开机后执行 `SET_KINEMATIC_POSITION`，不归零也能移动，坐标是错的，新机器上容易撞机。调试期间把这一段整段注释掉。
3. **多头热端数量**：把插件设置 `[multitool] tool_count`、热端定义的个数（`[extruder]`..`[extruderN]` 及对应停靠坞风扇）、对刀校准里的 `_TOOL_CALIB_VARS variable_tool_count` 统一成实际热端数量，多余的 `[extruderN]` 段和对应风扇段注释掉。

## 第 6 步：首次启动

在网页控制台执行 `FIRMWARE_RESTART`，确认没有报错、所有 MCU 都已连接。有报错先按提示修好配置。

## 第 7 步：基础检查（不要归零，不要加热）

1. **温度读数**：所有热端、热床、板载温度都显示室温附近（约 15～35°C）。显示 -200 多度或几百度说明热敏没接好或类型不对。
2. **限位**：执行 `QUERY_ENDSTOPS`，手动按下 X、Y 限位，状态应该从 `open` 变成 `TRIGGERED`。
3. **电机方向**：逐个执行下面的命令，观察电机是否先正转再反转：
   ```
   STEPPER_BUZZ STEPPER=stepper_x
   STEPPER_BUZZ STEPPER=stepper_y
   STEPPER_BUZZ STEPPER=stepper_z
   STEPPER_BUZZ STEPPER=stepper_z1
   STEPPER_BUZZ STEPPER=stepper_z2
   ```
   重点检查：**三个 Z 电机必须同向**（都先上升或都先下降），方向不对就在该电机的 `dir_pin` 前加上或去掉 `!`。
4. **风扇**：用 `M106 S128` 测试模型风扇，`M107` 关闭。

## 第 8 步：XY 归零与行程

1. 把喷嘴手动移到打印区中间，执行 `G28 X`，再执行 `G28 Y`，手放在急停上。
   - 往反方向跑：CoreXY 的方向调整需要同时考虑两个电机，按 Klipper 文档调整 `stepper_x`/`stepper_y` 的 `dir_pin`。
2. 归零后用控制面板小步移动，确认 X 能走到 0～290、Y 能走到 0～300，不撞机械限位。不同时修改 `modules/core/mainboard.cfg` 里的 `position_max` 和 `position_endstop`。

## 第 9 步：PID 温控校准

```
PID_CALIBRATE HEATER=heater_bed TARGET=60
PID_CALIBRATE HEATER=extruder TARGET=220
SAVE_CONFIG
```
多热端还要对每个热端执行一遍：`PID_CALIBRATE HEATER=extruder1 TARGET=220`，以此类推，最后 `SAVE_CONFIG`。

## 第 10 步：涡流探针校准

1. 校准驱动电流：
   ```
   LDC_CALIBRATE_DRIVE_CURRENT CHIP=eddy_probe
   SAVE_CONFIG
   ```
2. 校准高度曲线（垫一张 A4 纸）：
   ```
   PROBE_EDDY_CURRENT_CALIBRATE_AUTO
   ```
   用 `TESTZ Z=-0.1` 之类的命令慢慢降低喷嘴，直到纸张抽动时有轻微阻力，执行 `ACCEPT`，再执行 `SAVE_CONFIG`。
3. 检查精度：
   ```
   G28
   PROBE_ACCURACY
   ```
   标准差（standard deviation）应在 0.005mm 以内。

## 第 11 步：三点调平

1. 量出三根丝杆的实际中心坐标，填到 `modules/leveling/z_tilt.cfg` 的 `z_positions`。
2. ⚠️ **检查测点不能靠近热床边缘**（这是之前热床倾斜问题的根因，见 `docs/热床倾斜调试与修复记录.md`）：
   - `points` 填的是喷嘴坐标，探针实际位置要再加上 `y_offset`（20mm）。
   - 探针实际位置离热床边缘、螺丝、孔位至少 30mm。
   - 验证方法：在每个测点执行 `PROBE`，前后几个点的读数应该连续变化，不能突然跳变。
3. 执行调平：
   ```
   G28
   Z_TILT_ADJUST
   ```
   正常情况下几轮之内三点高差就小于 0.0075mm。如果出现 `Retries aborting: Probed points range is increasing`，检查 Z 电机方向和 `z_positions`。

## 第 12 步：网床与实测

```
G28
Z_TILT_ADJUST
G28 Z
BED_MESH_CALIBRATE
```
- 差值在 0.1～0.15mm 以内为正常。如果最后一排突然下降，就是边缘干扰，减小 `modules/leveling/bed_mesh.cfg` 里的 `mesh_max`。
- 用塞尺测试确认结果：执行 `PAPER_TEST_PREP`，再依次执行 `PAPER_TEST POINT=1` 到 `POINT=4`，4 个角的手感应该一致。
- 满意后执行 `SAVE_CONFIG` 保存网床。

## 第 13 步：共振补偿

```
G28
SHAPER_CALIBRATE
SAVE_CONFIG
```
看控制台输出里推荐的最大加速度，把 `modules/core/mainboard.cfg` 里 `[printer]` 的 `max_accel` 调到不超过这个值（当前是 10000）。

## 第 14 步：挤出与第一层

1. **挤出距离**：加热喷头，抽出 100mm 料，量实际挤出长度，按比例修正 `rotation_distance`：新值 = 旧值 × 实际长度 / 100。
2. **启用打印升温**：把 `modules/macros/print.cfg` 的 `PRINT_START` 里注释掉的热床和喷头升温恢复（删掉行首的 `# `）。
3. **切片软件开始 G-code**：`PRINT_START BED=[bed_temperature_initial_layer_single] EXTRUDER=[nozzle_temperature_initial_layer]`（变量名以所用的切片软件为准），并开启"标记对象"（Label objects）。
4. **第一层**：打一个单层方块，边打边微调 Z 偏移，满意后执行 `Z_OFFSET_APPLY_PROBE`、`SAVE_CONFIG`。
5. **压力提前、流量**：用切片软件自带的校准测试件确定。

## 第 15 步：多热端专项（仅多热端）

1. **停靠坞坐标**：手动把工具头移到每个停靠坞的位置，记下坐标，填到 `modules/multitool/changer_cxchanger.cfg` 的 `variable_tN_dock_x` / `variable_tN_dock_y`。同时检查 `dock_shift_x`、`dock_dodge_y`、`dock_safe_y`。
2. **低速试换头**：先把 `feed_safe` / `feed_fast` / `feed_slow` 调低，执行 `T0`、`T1`，确认抓取和放回动作正确后再恢复速度。
3. **对刀线圈位置**：把喷嘴移到对刀线圈正上方，记下坐标，填到 `modules/multitool/tool_calibrate_eddy.cfg` 的 `coil_x` / `coil_y` / `coil_z`，并检查 `_TOOL_CALIB_VARS` 的安全位置 `safe_x` / `safe_y` / `safe_z`。
4. **工具偏移校准**：
   ```
   LDC_CALIBRATE_DRIVE_CURRENT CHIP=calibrator_xy
   CALIBRATE_TOOL TOOL=0
   CALIBRATE_TOOL TOOL=1
   ```
   单个工具都没问题后，再用 `CALIBRATE_ALL_TOOLS` 批量校准。结果保存在 `myvariables.cfg`。

## 第 16 步：收尾

1. 把第 5 步注释掉的 `[delayed_gcode KINEMATIC_POSITION]` 保持注释（建议），或在确认安全后恢复。
2. 把打印机上调好的配置同步回仓库并提交，方便下次部署：
   ```bash
   cp -r ~/printer_data/config/. ~/printer-config/config/
   cd ~/printer-config && git add -A && git commit -m "新机器校准完成"
   ```

## 常见问题速查

| 现象 | 先检查 |
|---|---|
| `Include file '.../modules/...' does not exist` | `modules/` 没上传（网页上传不传文件夹）；或者多套了一层 `config/config/`；或者文件属主是 root。见第 1 步 |
| 启动报 `Option 'xxx' is not valid` | 拔掉模块后残留了只属于它的设置，例如涡流的 SAVE_CONFIG 数据 |
| 网床呈单方向平面倾斜 | 是否先执行了 `Z_TILT_ADJUST`；调平测点是否靠近边缘（见调试记录） |
| 每次重启后第一次调平高差很大 | 正常，Z 电机断电后热床会移位，重启后要先调平再扫床 |
| `Move out of range` | 坐标超出行程；校准时探针偏移会让喷嘴移到更靠前的位置 |
| 打印中途 Klipper Shutdown | 在 `klippy.log` 中搜索 `Shutdown`，常见原因是 CAN 通讯超时或加热保护 |

## 单文件调试配置

`debug/printer.cfg` 是一份不引用任何其它文件的调试配置，只包含 XYZ 运动、涡流探针、三点调平、网床和简单的打印头，适合新机器先把运动和调平调通：

1. 复制为 `~/printer_data/config/printer.cfg`（先备份原文件），填写主板和工具头的 `canbus_uuid`。
2. 还没装或没接的硬件，把对应整段注释掉（文件里每段都标了【必需】或【可选】）。
3. 调试速度和加速度已经降低，注释里写了正式值。
4. 常用命令：`LEVEL_ALL`（归零 → 调平 → 重新 Z 归零 → 扫床）、`PAPER_TEST POINT=1~4`（塞尺测试）、`PROBE_EDDY_CURRENT_CALIBRATE_AUTO`（涡流首次校准）。
5. 调通后换回 `config/` 的正式模块化配置，把 SAVE_CONFIG 数据块搬到正式 `printer.cfg` 的最底部。
