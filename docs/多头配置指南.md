# 多头配置指南（以 2 个打印头 T0 + T1 为例）

本文说明如何把仓库里的模块化配置（`config/`）从单头切换为多头。硬件：TGL36V3 工具头（挤出机步进在工具头上，各热端共用）、multihotend 扩展板（USB，负责各热端的加热、热敏和停靠坞风扇）、CxChanger 换头机构、主板上的涡流对刀线圈。

> 文中的行号对应编写本文时的文件，修改前请以实际内容为准。热端数量不是 2 个时，按同样的方法增减。

---

## 一、前提

1. 第 0～1 步按 `docs/新机器配置指南.md` 完成：Klipper 已安装，配置已部署，`modules/` 和 `printer.cfg` 在同一层。
2. 已安装两个插件：
   - klipper-multitool-stats：提供 `[multitool]`、`T0`/`T1`/`UNTOOL`、M104/M109 覆写
   - 涡流对刀插件 tool_eddy_calibration：提供 `[tool_eddy_calibration]`、`TOOL_EDDY_CALIBRATE` 等命令。下载 `tool_eddy_calibration.py` 放到 `~/klipper/klippy/extras/`，重启 Klipper 服务。需要较新的 Klipper（复用 `ldc1612.py`）
     - 源码：https://github.com/chengxg/tool_eddy_calibration
     - 教程：https://demo.chengxg.top/pangxie/articles/eddy-calibration/
   - 换热端方案参考：Simple-Multi-Hotend，https://github.com/cx330-TXY/Simple-Multi-Hotend
3. 单头状态下 XYZ 运动、涡流探针、调平都已调通。没有调通的话，先用 `debug/printer.cfg` 调好。

## 二、多头用到的模块

`profile_multitool.cfg` 与单头相比，少了单头挤出机模块，多了 4 个多热端模块：

| 模块 | 作用 |
|---|---|
| `modules/multitool/multihotend.cfg` | 扩展板 MCU、引脚别名、各停靠坞风扇、T0 挤出机（步进在工具头，加热在扩展板）、T1..T7 热端 |
| `modules/multitool/multitool_plugin.cfg` | 切换插件主配置（`tool_count` 等）、持久化变量、M104/M109 覆写 |
| `modules/multitool/changer_cxchanger.cfg` | 停靠坞坐标、抓取/放回动作、插件调用的两个钩子宏 |
| `modules/multitool/tool_calibrate_eddy.cfg` | 涡流对刀线圈、对刀参数、`CALIBRATE_TOOL` / `CALIBRATE_ALL_TOOLS`（可选） |

## 三、配置修改（固定改法）

### 1. 切换到多头机型

`config/printer.cfg`：

```
#单热端
# [include profile_singletool.cfg]      ← 注释掉

#多热端
[include profile_multitool.cfg]         ← 取消注释
```

### 2. 注释掉没装的热端 T2～T7

`modules/multitool/multihotend.cfg` 默认定义了 8 个热端。没装的热端没接热敏，温度读数异常会让 Klipper 报错停机，所以必须注释掉：

| 要注释的段 | 位置（约） |
|---|---|
| `[heater_fan dock_fan_t2]` ～ `[heater_fan dock_fan_t7]`（6 段停靠坞风扇） | 第 59～112 行 |
| `[extruder2]` ～ `[extruder7]`（6 段热端） | 第 219～314 行 |

每段从注释说明行开始，到下一段之前，整段每行前加 `# `。

⚠️ 不要用放宽温度范围（如 `max_temp: 9999`）的办法绕过没接热敏的报错，这会同时关闭真实热端的保护。

### 3. 恢复 T0、T1 的温度保护

同一个文件，`[extruder]`（T0，第 180～181 行）和 `[extruder1]`（T1，第 210～211 行）：

```
min_temp: 0          # 原来是 -210
max_temp: 300        # 原来是 9999，按热端实际上限填写
```

### 4. 统一工具数量

三处要一致，都等于实际热端数量（2）：

| 位置 | 设置 | 当前值 |
|---|---|---|
| `multitool_plugin.cfg` 第 38 行 | `tool_count: 2` | 已经是 2 |
| `tool_calibrate_eddy.cfg` 第 45 行 | `variable_tool_count: 2` | **8，要改** |
| `multihotend.cfg` | 启用的 `[extruder]`、`[extruder1]` | 第 2 步之后为 2 个 |

`variable_tool_count` 不改的话，`CALIBRATE_ALL_TOOLS` 会去校准不存在的 T2～T7。

### 5. 喉管风扇监听两个热端

`modules/toolhead/tgl36v3.cfg` 第 70 行：

```
heater: extruder, extruder1
```

喉管风扇装在工具头上，不管装上的是哪个热端都要转。原配置只监听 `extruder`，T1 加热时风扇不转，容易堵料。

### 6. 多头的行程允许负值

停靠坞在热床前方，换头时 Y 会走到负值（停靠坞中心 `dock_y`、避让位置 `dock_y + dock_dodge_y`）。单头的 Y 行程是 0～300，多头不放开会报：

```
Move out of range: 282.000 -1.000 1.987 [0.000]
```

`profile_multitool.cfg` 最后已经加了只对多头生效的覆盖（同名段写在所有 include 之后，会覆盖 `mainboard.cfg` 里的值，单头不受影响）：

```
[stepper_y]
position_min: -30          # 【待测试】停靠坞 Y 在 -20～-30 之间
```

- 停靠坞 Y 的实际值在 -20～-30 之间，**待测试**。实测确定 `tN_dock_y` 后，把 `position_min` 改为"最深的 dock_y 再留 3～5mm"。
- ⚠️ 改之前先低速确认工具头真的能走到这个位置，不会撞机架。
- X 方向同理：所有 `tN_dock_x` 都必须在 X 行程 0～290 以内。例如 `t0_dock_x: 295` 超过了 290，会报 `Move out of range: 295.000 ...`，需要按实测改小。如果停靠坞确实在 X 限位开关外侧，工具头物理上到不了，只能调整停靠坞或限位开关的位置。

## 四、按实物核对（数值要实测）

| 项目 | 文件与位置 | 怎么得到 |
|---|---|---|
| 扩展板串口 | `multihotend.cfg` 第 23 行 `serial:` | 打印机上执行 `ls /dev/serial/by-id/` |
| T0/T1 加热与热敏引脚 | `multihotend.cfg` 第 35～36 行 `T0H/T0S`、`T1H/T1S` | 对照扩展板实际接线 |
| T0/T1 停靠坞风扇引脚 | `multihotend.cfg` `IO0`、`IO1` | 对照扩展板实际接线 |
| 停靠坞坐标 | `changer_cxchanger.cfg` 第 45～48 行 `t0_dock_x/y`、`t1_dock_x/y` | 手动把工具头移到每个停靠坞中心，记下坐标（注意：t1 那两行的注释误写成了"T0"） |
| 换头动作参数 | `changer_cxchanger.cfg` 的 `dock_shift_x`、`dock_dodge_y`、`dock_safe_y` | 按 CxChanger 机构实测：摆臂开合的 X 横移、磁吸分离的 Y 避让、停靠坞前的安全距离 |
| 换头速度 | `changer_cxchanger.cfg` 的 `feed_safe`、`feed_fast`、`feed_slow` | 调试时先调低，确认动作正确后再恢复 |
| 对刀线圈位置 | `tool_calibrate_eddy.cfg` 第 28～30 行 `coil_x/y/z` | 把喷嘴移到线圈正上方记下坐标；`coil_z` 为线圈平面高度 |
| 对刀安全位置 | `tool_calibrate_eddy.cfg` 第 42～44 行 `safe_x/y/z` | 换头和待机时工具头停放的位置，不能和停靠坞、线圈干涉 |

## 五、调试步骤

### 1. 首次启动

执行 `FIRMWARE_RESTART`，确认主板、工具头、扩展板三块板都已连接，没有报错。检查 T0、T1 的温度读数都在室温附近。

### 2. 热端 PID（对刀前必须做）

热端 PID 参数出厂是安装脚本给的**占位值**（`pid_kp: 26.213` 等），不校准的话温度会过冲、上下摆动（本机实测目标 150°C 时在 155～157°C 来回跳）。一键对刀宏里的 `M109 S150` 要等温度稳定在目标 ±1.5°C 才继续，PID 不准会**一直卡在"T0 等温中 (target=150.0)..."**。

```
M106 S0                                       ; 关模型风扇；喉管风扇超过 50°C 会自动转，保持和对刀时一致
PID_CALIBRATE HEATER=extruder TARGET=150
PID_CALIBRATE HEATER=extruder1 TARGET=150
```

⚠️ **不要用 `SAVE_CONFIG` 保存**：PID 写在被引用的 `modules/multitool/multihotend.cfg` 里，SAVE_CONFIG 不能覆盖引用文件里的设置，会报冲突（同教程第 19 条）。把控制台输出的 `pid_Kp`、`pid_Ki`、`pid_Kd` **手动填进** `multihotend.cfg` 中 `[extruder]`（第二个、带 `heater_pin: multihotend:T0H` 的那段）和 `[extruder1]`，执行 `RESTART`，再用 `M109 S150` 确认能稳定在 ±1°C 以内。

对刀用 150°C 校准；正常打印温度（如 220°C）可以之后再校准一次。另外检查两个停靠坞风扇：热端超过 50°C 时对应风扇应启动。

### 3. 换头动作

1. 先把 `feed_safe`、`feed_fast`、`feed_slow` 调低（比如 3000 / 600 / 200），执行 `FIRMWARE_RESTART`。
2. `G28` 归零后，依次执行下面的命令，手放在急停上，观察每一步动作：
   ```
   T0          ; 抓取 T0
   UNTOOL      ; 放回
   T1          ; 抓取 T1
   T0          ; 放回 T1，抓取 T0
   ```
3. 动作有偏差时，调整停靠坞坐标和 `dock_shift_x`、`dock_dodge_y`；确认无误后再恢复速度。

### 4. 涡流对刀（测各工具的 XYZ 偏移）

对刀用两个传感器：
- **Z**：工具头上的涡流探针，用 tap 模式（喷嘴轻触热床）测出每个热端的 Z。对刀线圈本身**只能测 XY**，Z 必须靠 tap 或压力床这类喷嘴限位探针。
- **XY**：固定在热床上、接到主板的对刀线圈 `calibrator_xy`（LDC1612）。喷嘴扫过线圈中心时频率呈抛物线变化，极值点就是中心；从至少两个方向扫过，就能算出喷嘴中心。

结果都相对 T0 计算，T0 的偏移固定为 0。参考精度（来自教程）：不换热端的重复精度在 0.005～0.01mm，换热端后的固定偏移精度在 0.02mm 以内。

**一键对刀操作流程（总览）**

前置条件全部满足后，对刀只需要：

```
G28
CALIBRATE_TOOL TOOL=0        ; T0 是基准，必须先做
CALIBRATE_TOOL TOOL=1        ; 两次之间不要再 G28
T1                           ; 检查输出的"T1 加载校准值"
```

| 前置条件 | 说明 | 本机状态 |
|---|---|---|
| 换头动作正常 | 第五节第 3 步 | ✅ |
| 热端 PID 已校准 | 第五节第 2 步，否则卡在"等温中" | ⏳ |
| 工具数量一致 | `variable_tool_count` = `[multitool] tool_count` = 2 | ✅ |
| `ldc1612.py` 三处修改 + SciPy | 4.1 A | ✅ |
| `max_z_accel: 200` | 4.1 B | ✅ |
| 涡流探针热机校准 | 4.1 C | ✅ |
| tap 阈值已校准并保存 | 4.1 D | ✅ `tap_threshold: 64820.919` |
| 对刀线圈正常、位置正确 | 4.0、4.2 | ✅ |

> 对刀线圈走 I2C，占用资源较多，要接主频较高的 MCU。教程明确指出 STM32F072 不行（除非按涡流扫床教程把 `ldc1612.py` 的采样速率改低），所以线圈接在主板（STM32F446）上，**不要改接到多热端扩展板（STM32F072）**。

#### 4.0 检查对刀线圈

焊接、接线完成后，先确认传感器工作正常：

```
TEST_LDC1612
```

会采集一小段频率数据并输出统计信息，线圈谐振频率应在 2.2MHz 左右。

本机实测：

| 采样率 | 频率 | 波动范围 | 标准差 | 100ms 采样数 |
|---|---|---|---|---|
| 400 次/秒（默认） | 2,291,254.7Hz | 16.8Hz | 4.0Hz | 36（预期约 40） |
| 250 次/秒（`data_rate` 改后） | 2,294,555.5Hz | 7.3Hz | 1.5Hz | 24（预期约 25） |

两种都是 EXCELLENT，改成 250 后噪声降到一半以下。

#### 4.1 涡流探针 tap 校准（本机已调通）

`CALIBRATE_TOOL` 用 `PROBE METHOD=tap SAMPLES=3` 测每个热端的 Z，命令里不带阈值，**配置或 SAVE_CONFIG 中必须已有 `tap_threshold`**，否则报 `Tap not configured`。

参考：小螃蟹涡流扫床教程 https://demo.chengxg.top/pangxie/articles/eddy-coil/ （"修改 klipper 涡流驱动代码""首次校准涡流时的命令""报错问题汇总"三节）。按下面 A→D 的顺序做。

**A. 修改涡流驱动 `~/klipper/klippy/extras/ldc1612.py`（教程第二节）**

| 位置 | 原值 | 改为 | 作用 |
|---|---|---|---|
| `SETTLETIME` | `0.005` | `0.0002` | 线圈断线时仍有数据返回，避免撞机 |
| `self.set_reg(REG_ERROR_CONFIG, ...)` | `(0x1f << 11) \| 1` | `(0x1c << 11) \| 1` | 关闭振幅错误报告 |
| `self.data_rate` | `400` | `250` | **工具头板是 STM32F072（低主频、软件 I2C），400 次/秒负担过重** |

```bash
cp ~/klipper/klippy/extras/ldc1612.py ~/ldc1612.py.bak
vim ~/klipper/klippy/extras/ldc1612.py
grep -n "SETTLETIME\|REG_ERROR_CONFIG\|data_rate" ~/klipper/klippy/extras/ldc1612.py
```

`data_rate` 改成 250 后，tap 的数字滤波器需要 SciPy，不装会报 `DigitalFilter require the SciPy module` 并停机（教程第 5 条）：

```bash
~/klippy-env/bin/pip install scipy -i https://pypi.tuna.tsinghua.edu.cn/simple
~/klippy-env/bin/python -c "import scipy; print(scipy.__version__)"
sudo systemctl restart klipper
```

修改 `.py` 文件后必须**重启 Klipper 服务**（`FIRMWARE_RESTART` 不会重新加载 Python 文件）。以后更新 Klipper 时这些修改可能被覆盖，更新后用上面的 `grep` 检查。

**B. Z 轴加速度提高到 200（源码分析得出，教程没有）**

本机最初 `max_z_accel: 50`，tap 反复报 `insufficient lift` 和斜率差为负数的 `insufficient slope delta`。Klipper 源码（`klippy/extras/probe_eddy_current.py`）中：

```python
# tap 触发后以 lift_speed（默认 5mm/s）抬起
start_time = retract_start_time - 0.010
end_time   = retract_start_time + 0.150      # 只取抬起开始后 0.15 秒的数据
if max_z - min_z < 0.350:                    # 这段时间内 Z 至少要走 0.35mm
    self._error_detect("insufficient lift ...")
contact_slope_delta = depress_slope - slope  # 接触段斜率 - 悬空段斜率，正常为大正数
```

加速度 50mm/s² 时 0.15 秒内只能抬起 0.27～0.34mm，悬空段数据太少，拟合把接触段和悬空段分错，斜率差变成大负数。已改为 `max_z_accel: 200`（`modules/core/mainboard.cfg`，`debug/printer.cfg` 同步）。改后注意 Z 轴有无丢步，跑一次 `Z_TILT_ADJUST` 确认正常。

`PROBE_ACCURACY` 输出里的 `retract=0.000` 是源码写死的，属于正常；`SAMPLE_RETRACT_DIST` 在 tap 中不影响 0.15 秒的采样窗口。

**C. 热机重新校准涡流探针（教程第三节 1、2 条）**

用涡流做 Z 限位时，校准要在**热床 80°C、喷嘴 150°C、喷嘴擦干净**的条件下做；`A` 改完后采样率变了，旧校准不能再用。

```
M140 S80
M109 S150
M190 S80
```

到温后擦干净喷嘴：

```
G28
LDC_CALIBRATE_DRIVE_CURRENT CHIP=eddy_probe     ; 在喷嘴靠近热床（约 2mm）处校准
SAVE_CONFIG
```

重启后重新加热到温，再：

```
PROBE_EDDY_CURRENT_CALIBRATE_AUTO               ; 垫 A4 纸，TESTZ 调到轻微阻力，ACCEPT
SAVE_CONFIG                                     ; 等噪声数据打印出来后一定要保存
```

`reg_drive_current` 在配置里要保持注释，否则 SAVE_CONFIG 报冲突（教程第 19 条）。

本机记录（2026-10-20 01:03，热机、250 次/秒）：驱动电流 24；噪声 0.001025mm，MAD_Hz=162.6，频率范围 613518Hz。MAD 比冷机、400 次/秒时（31Hz）大，可能与热床加热干扰、采样次数减少有关；换算成距离只有 0.001mm，不影响使用。

⚠️ 重新校准高度曲线后 Z 基准会变，之后要重新执行 `G28`、`Z_TILT_ADJUST`、`G28 Z`、`BED_MESH_CALIBRATE`，并重新调第一层。

**D. tap 阈值自动校准（教程第三节第 3 条）**

保持热机、喷嘴干净，`tap_threshold` 在配置里保持注释：

```
G28
G1 X150 Y150 Z5 F6000
PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=guess
PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=refine
PROBE_EDDY_CURRENT_TAP_CALIBRATE TAP=verify
SAVE_CONFIG
```

本机结果（A～C 完成后一次成功）：

| 步骤 | 阈值 | 结果 |
|---|---|---|
| guess | 37396.625 | z=-0.1723 |
| refine | 64820.919 | z=-0.1788 |
| verify（5 次） | 64820.919 | -0.1777、-0.1769、-0.1849、-0.1842、-0.1851，**极差 0.008mm** |

`tap_threshold: 64820.919` 已由 SAVE_CONFIG 写入 `printer.cfg` 底部。

如果自动校准报阈值不对，按教程改用手动找：`PROBE_ACCURACY METHOD=tap tap_threshold=40000`，按结果调整（半空停止 → 调高；`invalid depress distance` → 与热床刚性有关），10 次标准差 ≤0.01mm 后把值写进 `modules/probe/eddy_tgl36v3.cfg`。

**调试过程记录（供排查参考）**

| 阶段 | 现象 | 原因 |
|---|---|---|
| 冷机、驱动未改、加速度 50 | `TAP=guess` 报 slope delta 负数；手动找阈值时 `insufficient lift` | 抬起距离不足 |
| 改加速度 200 | 能检测到接触，但 10 次极差 0.07～0.24mm | 驱动未改、采样率过高（F072） |
| 改 `SETTLETIME`/`REG_ERROR_CONFIG` | 仍分散 | 同上 |
| 试 spreadCycle、调阈值、`LIFT_SPEED` | 无改善 | 不是这些原因 |
| `data_rate` 250 + SciPy + 热机重新校准 | 自动校准一次通过，极差 0.008mm | ✅ |

#### 4.2 设置对刀线圈位置

在 `modules/multitool/tool_calibrate_eddy.cfg` 中：

1. 用 T0，`G28` 后把喷嘴慢慢移到线圈中心正上方，记下大概的 X、Y，填 `coil_x`、`coil_y`。这里只需要大概位置，误差要在 `scan_length`（4mm）的扫描范围以内。
2. 线圈表面垫一张纸，喷嘴慢慢降到刚好压住纸，记下 Z，填 `coil_z`（线圈平面的 Z 坐标）。
3. `scan_height` 是在 `coil_z` 基础上再抬高的距离，要让喷嘴在线圈上方约 0.5mm 处扫过（教程示例 `coil_z: 0.4`、`scan_height: 0.4`）。`scan_safe_z` 比扫描高度高即可。
4. **本机实测记录**：
   - 喷嘴对准线圈的粗略位置：X=168.16、Y=284.85
   - 垫纸（约 0.1mm）有轻微阻力时 Z=0.95，所以 `coil_z: 0.85`（原配置 0.3 偏差很大）
   - `scan_height` 由 0.8 改为 `0.5`，扫描时喷嘴在 Z=1.35。原配置 0.3+0.8=1.1，离实际线圈只有约 0.25mm，有撞线圈风险
5. 检查 `_TOOL_CALIB_VARS` 的 `safe_x`、`safe_y`、`safe_z`（当前 20, 35, 5）：宏会在这里换头、加热、用 tap 测 Z，必须在热床上方空旷处，不能和停靠坞、线圈干涉。
6. 执行 `RESTART`。

#### 4.3 校准对刀线圈驱动电流

```
LDC_CALIBRATE_DRIVE_CURRENT CHIP=calibrator_xy
```

配置里写死了 `reg_drive_current: 22`。用校准结果的话，把这一行改成输出的值；或者按注释去掉这一行，让 SAVE_CONFIG 保存。

#### 4.4 校准 T0（基准，必须第一个做）

```
CALIBRATE_TOOL TOOL=0
```

宏的动作：移到安全位置 → 换上 T0 → 清零 G-code 偏移 → 加热到 150°C（软化喷嘴残料，tap 更准）→ tap 测 Z → 在线圈上扫描找中心 → 保存（T0 固定存 0）。

宏每次会先 `CLEAR_TOOL_CENTER` 清掉缓存的中心点，所以扫描都会从 `coil_x/coil_y` 开始，先预扫描把大概位置精确化，再沿 X、Y（`DIR=0,90`）精确扫描。**第一次校准 T0 后，把输出的中心点坐标回填到 `coil_x`、`coil_y`**，以后预扫描会更快更稳。

T0 不先校准的话，其它工具没有参照，保存结果时会报错。

**调试建议：先单独测 XY，确认扫描正常后再用一键宏**

```
G28
CLEAR_TOOL_CENTER TOOL=0
TOOL_EDDY_CALIBRATE TOOL=0 DIR=0,90
GET_TOOL_CENTER TOOL=0
```

再执行两次 `TOOL_EDDY_CALIBRATE TOOL=0 DIR=0,90` 看重复精度。本机实测：

| 阶段 | 结果 | 说明 |
|---|---|---|
| 从粗略位置 (168.16, 284.85) 预扫描 | 中心 (168.0914, 283.7460) | Y 偏了约 1.1mm，4mm 扫描范围内能自动修正 |
| 首次连续 3 次 | X 差 0.0135，Y 差 0.0062 | X 逐次单向变化，判断为刚开始的温度变化 |
| 回填 `coil_x: 168.08`、`coil_y: 283.75`，重启后 2 次 | X 差 0.0043，Y 差 0.0026 | 达到教程的 0.005mm 重复精度 |

- 每次扫描的拟合度 R² 约 0.998，线圈中心处频率由约 2.291MHz 降到约 2.268MHz（`peak_type=valley`）。
- 重启并重新归零后，中心会偏约 0.01mm，这是 X 限位开关的重复误差。偏移是相对 T0 计算的，**只要 T0 和其它工具在同一次归零后连续校准**（中间不要 `G28`）就不受影响。

#### 4.5 校准其它工具

```
CALIBRATE_TOOL TOOL=1
```

结果保存在 `myvariables.cfg`：`t1_offset_x`、`t1_offset_y`、`t1_offset_z`（相对 T0）。

单个工具都没问题后，以后可以用 `CALIBRATE_ALL_TOOLS` 一次校准全部。它会先把所有热端预热到 150°C，注意电源功率。

#### 4.6 检查结果

```
GET_TOOL_CENTER TOOL=0
GET_TOOL_CENTER TOOL=1
```

- 查看 `~/printer_data/config/myvariables.cfg`，应该有 `t1_offset_x/y/z`。
- 连续校准 T1 两三次，每次相差在 0.02mm 以内说明结果稳定。差得多时检查：线圈坐标、`scan_height`、喷嘴是否干净。

| 对刀相关命令 | 作用 |
|---|---|
| `TEST_LDC1612` | 检测对刀线圈是否正常（谐振频率约 2.2MHz） |
| `TOOL_EDDY_CALIBRATE TOOL=0 DIR=45,135 REPEATS=1` | 手动寻找喷嘴中心（需已归零） |
| `GET_TOOL_CENTER TOOL=0` | 查询校准结果 |
| `SET_TOOL_Z TOOL=0 Z=-0.1` | 设置工具 Z 坐标（插件不测 Z，值来自 tap/压力床探针） |
| `CLEAR_TOOL_CENTER TOOL=0` | 清除缓存的中心点，下次扫描会重新预扫描 |
| `LDC_CALIBRATE_DRIVE_CURRENT CHIP=calibrator_xy` | 线圈驱动电流校准 |

`TOOL_EDDY_CALIBRATE` 常用参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `DIR` | `45,135` | 扫描方向角度，0°=X+，90°=Y+，至少两个方向。本配置的宏用 `0,90` |
| `PRE_DIR` | 同 `DIR` | 预扫描方向，用于把 `coil_x/coil_y` 精确化 |
| `REPEATS` | 1 | 重复测量取平均（1～10），一般 1 次就够 |
| `PAIR_CANCEL` | 0 | 1 = 自动增加反方向扫描，消除皮带的运动滞后（正反向约差 0.03mm）。一般不用开 |
| `SCAN_HEIGHT_OFFSET` | 0 | 扫描高度微调（+ 远离线圈，- 靠近线圈）。宏会按各热端与 T0 的 Z 差自动设置，防止撞线圈 |
| `CENTER_XY` | — | 覆盖初始扫描中心，格式 `X,Y`。某个热端偏移太大、偏离线圈中心时使用 |

`save_data: True` 时会把扫描数据保存为 csv，可导入教程页面提供的工具查看频率波形（中心点处频率最低）。

#### 4.7 喷嘴偏心

涡流测到的是喷嘴的质心，不一定是出料孔中心。偏移都以 T0 为基准，T0 自己的偏心会叠加到其它热端的误差上。需要更高精度时：
- 在应用偏移时，给对应热端再加一个固定补偿值；
- 或者按教程的做法，做一个实心圆锥定位销当"假喷嘴"作为基准，理论上可以把固定误差减半。

### 5. 确认偏移已应用

已确认：**多热端插件换头时会自动加载对刀偏移**，不需要自己在钩子宏里写 `SET_GCODE_OFFSET`。执行 `T0` 时控制台会输出：

```
// T0 加载校准值: X=0.0000 Y=0.0000 Z=0.0000
```

对刀完成后检查：

1. 执行 `T1`，输出的"T1 加载校准值: X=… Y=… Z=…"应该等于 `myvariables.cfg` 中的 `t1_offset_x/y/z`。
2. 也可以再执行 `GET_POSITION`，看 `gcode base:` 的 X/Y/Z 是否等于这组偏移。

注意：手动测量（比如垫纸测 Z）前，要先执行 `SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0`，清掉换头时加载的偏移，否则测量值会带上旧偏移。`CALIBRATE_TOOL` 宏里已经包含这一步。

### 6. 打印测试

1. 恢复 `modules/macros/print.cfg` 中 `PRINT_START` 被注释的升温代码。
2. 切片软件设置 2 个挤出机，开始 G-code 中调用 `PRINT_START`，换色时会发出 `T0` / `T1`。
3. 先打一个两色的简单模型（例如两色叠层方块），检查两色之间 XY 是否对齐、层高是否一致；有偏差就重新对刀。

## 六、增减热端

以增加 T2 为例：

1. `multihotend.cfg`：取消 `[extruder2]` 和 `[heater_fan dock_fan_t2]` 的注释，并设置正常的温度范围。
2. `multitool_plugin.cfg`：`tool_count: 3`。
3. `tool_calibrate_eddy.cfg`：`variable_tool_count: 3`。
4. `changer_cxchanger.cfg`：实测并填写 `t2_dock_x/y`。
5. `tgl36v3.cfg`：喉管风扇 `heater:` 加上 `extruder2`。
6. 执行 `PID_CALIBRATE HEATER=extruder2 TARGET=220`，然后执行 `CALIBRATE_TOOL TOOL=2`。

## 七、常见问题

| 现象 | 先检查 |
|---|---|
| 启动报 `ADC out of range` 或热敏温度异常 | 是否还有没装的热端没注释掉 |
| `Move out of range: X Y Z` | 停靠坞坐标超出行程：Y 为负值时检查 `profile_multitool.cfg` 的 `position_min`；X 超过 290 时检查 `tN_dock_x`（见第三节第 6 步） |
| 启动报 `mcu 'multihotend': Unable to connect` | 扩展板串口 `serial:` 是否正确，USB 线是否接好 |
| T1 加热时喉管风扇不转 | `hotend_fan` 的 `heater:` 是否包含 `extruder1` |
| `DigitalFilter require the SciPy module`（停机） | 改了 `data_rate` 后需要 SciPy：`~/klippy-env/bin/pip install scipy -i https://pypi.tuna.tsinghua.edu.cn/simple`，再重启 Klipper 服务（第五节 4.1 A） |
| 对刀卡在"T0 等温中 (target=150.0)..." | 热端 PID 未校准，温度在目标附近来回摆，进不了 ±1.5°C。先做第五节第 2 步 |
| tap 结果分散（极差 >0.05mm） | 检查 `ldc1612.py` 三处修改（尤其 F072 工具头的 `data_rate: 250`）、热机重新校准涡流（第五节 4.1） |
| `Tap not configured` | tap 阈值没有生效。`CALIBRATE_TOOL` 里的 `PROBE METHOD=tap` 不带阈值参数，配置或 SAVE_CONFIG 中必须已有 `tap_threshold`；手动找阈值时用命令参数 `tap_threshold=`（第五节 4.1） |
| `Unable to detect tap: insufficient lift (0.3xx vs 0.350)` | Z 轴加速度太小，tap 后 0.15 秒内抬不够 0.35mm。把 `max_z_accel` 提高到 200（第五节 4.1） |
| `MULTITOOL_SET_TEMPERATURE TOOL=2 ...: TOOL must have maximum of 1` | `_TOOL_CALIB_VARS` 的 `variable_tool_count` 比 `[multitool] tool_count` 大，改成一致（2 个热端就是 2） |
| `CALIBRATE_ALL_TOOLS` 报找不到 T2 | `variable_tool_count` 是否和实际数量一致 |
| 换头时撞停靠坞 | 停靠坞坐标、`dock_safe_y` 是否准确；先降速调试 |
| `CALIBRATE_TOOL` 在测 Z 时失败 | tap 模式没启用，先做第五节 4.1 的 tap 阈值校准 |
| `Unable to detect tap: insufficient slope delta (负数 vs …)` | 先检查 `max_z_accel`（太小时抬起不足，拟合出错，斜率差会是负数）；加速度正常后仍报，再按教程用 `PROBE_ACCURACY METHOD=tap tap_threshold=…` 手动找阈值（第五节 4.1） |
| 对刀扫描找不到中心 | `coil_x/y` 粗略位置偏差超过扫描范围（4mm），或 `coil_z`/`scan_height` 不对导致喷嘴离线圈太远 |
| `CALIBRATE_TOOL TOOL=1` 保存结果时报错 | 没有先校准 T0（第五节 4.4） |
| 两色错位 | 对刀偏移是否已应用（第五节第 5 步）；对刀线圈坐标是否准确 |
