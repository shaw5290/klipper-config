# 多头配置指南（以 2 个打印头 T0 + T1 为例）

本文说明如何把仓库里的模块化配置（`config/`）从单头切换为多头。硬件：TGL36V3 工具头（挤出机步进在工具头上，各热端共用）、multihotend 扩展板（USB，负责各热端的加热、热敏和停靠坞风扇）、CxChanger 换头机构、主板上的涡流对刀线圈。

> 文中的行号对应编写本文时的文件，修改前请以实际内容为准。热端数量不是 2 个时，按同样的方法增减。

---

## 一、前提

1. 第 0～1 步按 `docs/新机器配置指南.md` 完成：Klipper 已安装，配置已部署，`modules/` 和 `printer.cfg` 在同一层。
2. 已安装两个插件：
   - klipper-multitool-stats：提供 `[multitool]`、`T0`/`T1`/`UNTOOL`、M104/M109 覆写
   - Simple-Multi-Hotend 涡流对刀插件：提供 `[tool_eddy_calibration]`，https://github.com/cx330-TXY/Simple-Multi-Hotend
3. 单头状态下 XYZ 运动、涡流探针、调平都已调通。没有调通的话，先用 `debug/printer.cfg` 调好。

## 二、多头用到的模块

`profile_multitool.cfg` 与单头相比，少了单头挤出机模块，多了 4 个多热端模块：

| 模块 | 作用 |
|---|---|
| `modules/multitool/multihotend.cfg` | 扩展板 MCU、引脚别名、各停靠坞风扇、T0 挤出机（步进在工具头，加热在扩展板）、T1..T7 热端 |
| `modules/multitool/multitool_plugin.cfg` | 切换插件主配置（`tool_count` 等）、持久化变量、M104/M109 覆写 |
| `modules/multitool/changer_cxchanger.cfg` | 停靠坞坐标、抓取/放回动作、插件调用的两个钩子宏 |
| `modules/multitool/tool_calibrate_eddy.cfg` | 涡流对刀线圈、对刀参数、`CALIBRATE_TOOL` / `CALIBRATE_ALL_TOOLS`（可选） |

## 三、配置修改（固定改法）

### 1. 切换到多头机型

`config/printer.cfg`：

```
#单热端
# [include profile_singletool.cfg]      ← 注释掉

#多热端
[include profile_multitool.cfg]         ← 取消注释
```

### 2. 注释掉没装的热端 T2～T7

`modules/multitool/multihotend.cfg` 默认定义了 8 个热端。没装的热端没接热敏，温度读数异常会让 Klipper 报错停机，所以必须注释掉：

| 要注释的段 | 位置（约） |
|---|---|
| `[heater_fan dock_fan_t2]` ～ `[heater_fan dock_fan_t7]`（6 段停靠坞风扇） | 第 59～112 行 |
| `[extruder2]` ～ `[extruder7]`（6 段热端） | 第 219～314 行 |

每段从注释说明行开始，到下一段之前，整段每行前加 `# `。

⚠️ 不要用放宽温度范围（如 `max_temp: 9999`）的办法绕过没接热敏的报错，这会同时关闭真实热端的保护。

### 3. 恢复 T0、T1 的温度保护

同一个文件，`[extruder]`（T0，第 180～181 行）和 `[extruder1]`（T1，第 210～211 行）：

```
min_temp: 0          # 原来是 -210
max_temp: 300        # 原来是 9999，按热端实际上限填写
```

### 4. 统一工具数量

三处要一致，都等于实际热端数量（2）：

| 位置 | 设置 | 当前值 |
|---|---|---|
| `multitool_plugin.cfg` 第 38 行 | `tool_count: 2` | 已经是 2 |
| `tool_calibrate_eddy.cfg` 第 45 行 | `variable_tool_count: 2` | **8，要改** |
| `multihotend.cfg` | 启用的 `[extruder]`、`[extruder1]` | 第 2 步之后为 2 个 |

`variable_tool_count` 不改的话，`CALIBRATE_ALL_TOOLS` 会去校准不存在的 T2～T7。

### 5. 喉管风扇监听两个热端

`modules/toolhead/tgl36v3.cfg` 第 70 行：

```
heater: extruder, extruder1
```

喉管风扇装在工具头上，不管装上的是哪个热端都要转。原配置只监听 `extruder`，T1 加热时风扇不转，容易堵料。

### 6. 多头的行程允许负值

停靠坞在热床前方，换头时 Y 会走到负值（停靠坞中心 `dock_y`、避让位置 `dock_y + dock_dodge_y`）。单头的 Y 行程是 0～300，多头不放开会报：

```
Move out of range: 282.000 -1.000 1.987 [0.000]
```

`profile_multitool.cfg` 最后已经加了只对多头生效的覆盖（同名段写在所有 include 之后，会覆盖 `mainboard.cfg` 里的值，单头不受影响）：

```
[stepper_y]
position_min: -30          # 【待测试】停靠坞 Y 在 -20～-30 之间
```

- 停靠坞 Y 的实际值在 -20～-30 之间，**待测试**。实测确定 `tN_dock_y` 后，把 `position_min` 改为"最深的 dock_y 再留 3～5mm"。
- ⚠️ 改之前先低速确认工具头真的能走到这个位置，不会撞机架。
- X 方向同理：所有 `tN_dock_x` 都必须在 X 行程 0～290 以内。例如 `t0_dock_x: 295` 超过了 290，会报 `Move out of range: 295.000 ...`，需要按实测改小。如果停靠坞确实在 X 限位开关外侧，工具头物理上到不了，只能调整停靠坞或限位开关的位置。

## 四、按实物核对（数值要实测）

| 项目 | 文件与位置 | 怎么得到 |
|---|---|---|
| 扩展板串口 | `multihotend.cfg` 第 23 行 `serial:` | 打印机上执行 `ls /dev/serial/by-id/` |
| T0/T1 加热与热敏引脚 | `multihotend.cfg` 第 35～36 行 `T0H/T0S`、`T1H/T1S` | 对照扩展板实际接线 |
| T0/T1 停靠坞风扇引脚 | `multihotend.cfg` `IO0`、`IO1` | 对照扩展板实际接线 |
| 停靠坞坐标 | `changer_cxchanger.cfg` 第 45～48 行 `t0_dock_x/y`、`t1_dock_x/y` | 手动把工具头移到每个停靠坞中心，记下坐标（注意：t1 那两行的注释误写成了"T0"） |
| 换头动作参数 | `changer_cxchanger.cfg` 的 `dock_shift_x`、`dock_dodge_y`、`dock_safe_y` | 按 CxChanger 机构实测：摆臂开合的 X 横移、磁吸分离的 Y 避让、停靠坞前的安全距离 |
| 换头速度 | `changer_cxchanger.cfg` 的 `feed_safe`、`feed_fast`、`feed_slow` | 调试时先调低，确认动作正确后再恢复 |
| 对刀线圈位置 | `tool_calibrate_eddy.cfg` 第 28～30 行 `coil_x/y/z` | 把喷嘴移到线圈正上方记下坐标；`coil_z` 为线圈平面高度 |
| 对刀安全位置 | `tool_calibrate_eddy.cfg` 第 42～44 行 `safe_x/y/z` | 换头和待机时工具头停放的位置，不能和停靠坞、线圈干涉 |

## 五、调试步骤

### 1. 首次启动

执行 `FIRMWARE_RESTART`，确认主板、工具头、扩展板三块板都已连接，没有报错。检查 T0、T1 的温度读数都在室温附近。

### 2. 热端 PID

```
PID_CALIBRATE HEATER=extruder TARGET=220
PID_CALIBRATE HEATER=extruder1 TARGET=220
SAVE_CONFIG
```

分别检查两个停靠坞风扇：热端超过 50°C 时，对应的风扇应该启动。

### 3. 换头动作

1. 先把 `feed_safe`、`feed_fast`、`feed_slow` 调低（比如 3000 / 600 / 200），执行 `FIRMWARE_RESTART`。
2. `G28` 归零后，依次执行下面的命令，手放在急停上，观察每一步动作：
   ```
   T0          ; 抓取 T0
   UNTOOL      ; 放回
   T1          ; 抓取 T1
   T0          ; 放回 T1，抓取 T0
   ```
3. 动作有偏差时，调整停靠坞坐标和 `dock_shift_x`、`dock_dodge_y`；确认无误后再恢复速度。

### 4. 涡流对刀（测各工具的 XYZ 偏移）

```
LDC_CALIBRATE_DRIVE_CURRENT CHIP=calibrator_xy    ; 对刀线圈驱动电流
CALIBRATE_TOOL TOOL=0                              ; T0 作为基准，偏移固定为 0
CALIBRATE_TOOL TOOL=1                              ; T1 相对 T0 的偏移
```

单个工具都没问题后，以后可以用 `CALIBRATE_ALL_TOOLS` 一次校准全部。结果保存在 `myvariables.cfg` 中，变量名为 `t1_offset_x`、`t1_offset_y`、`t1_offset_z`。

### 5. ⚠️ 确认偏移已应用

对刀结果只是保存在变量里，现有配置中**没有宏在换头时应用这些偏移**，需要确认插件会不会自动应用：

1. 执行 `T1`，再执行 `GET_POSITION`，看输出中 `gcode base:` 的 X/Y/Z。
2. 和 `T0` 时比较：差值等于 `myvariables.cfg` 中 T1 的偏移，说明已经生效。
3. 没有变化时，查插件是否读取这些变量：
   ```bash
   grep -rn "offset_x\|_offset" ~/klipper/klippy/extras/multitool*.py
   ```
   插件不读取的话，需要在 `changer_cxchanger.cfg` 的 `multitool_pickup_tool` 钩子里，抓取完成后用 `SET_GCODE_OFFSET` 应用保存的偏移。

### 6. 打印测试

1. 恢复 `modules/macros/print.cfg` 中 `PRINT_START` 被注释的升温代码。
2. 切片软件设置 2 个挤出机，开始 G-code 中调用 `PRINT_START`，换色时会发出 `T0` / `T1`。
3. 先打一个两色的简单模型（例如两色叠层方块），检查两色之间 XY 是否对齐、层高是否一致；有偏差就重新对刀。

## 六、增减热端

以增加 T2 为例：

1. `multihotend.cfg`：取消 `[extruder2]` 和 `[heater_fan dock_fan_t2]` 的注释，并设置正常的温度范围。
2. `multitool_plugin.cfg`：`tool_count: 3`。
3. `tool_calibrate_eddy.cfg`：`variable_tool_count: 3`。
4. `changer_cxchanger.cfg`：实测并填写 `t2_dock_x/y`。
5. `tgl36v3.cfg`：喉管风扇 `heater:` 加上 `extruder2`。
6. 执行 `PID_CALIBRATE HEATER=extruder2 TARGET=220`，然后执行 `CALIBRATE_TOOL TOOL=2`。

## 七、常见问题

| 现象 | 先检查 |
|---|---|
| 启动报 `ADC out of range` 或热敏温度异常 | 是否还有没装的热端没注释掉 |
| `Move out of range: X Y Z` | 停靠坞坐标超出行程：Y 为负值时检查 `profile_multitool.cfg` 的 `position_min`；X 超过 290 时检查 `tN_dock_x`（见第三节第 6 步） |
| 启动报 `mcu 'multihotend': Unable to connect` | 扩展板串口 `serial:` 是否正确，USB 线是否接好 |
| T1 加热时喉管风扇不转 | `hotend_fan` 的 `heater:` 是否包含 `extruder1` |
| `CALIBRATE_ALL_TOOLS` 报找不到 T2 | `variable_tool_count` 是否和实际数量一致 |
| 换头时撞停靠坞 | 停靠坞坐标、`dock_safe_y` 是否准确；先降速调试 |
| 两色错位 | 对刀偏移是否已应用（第五节第 5 步）；对刀线圈坐标是否准确 |
