# 新手必读：调试的基本操作

调试文档里的每一步都会用到这一页的操作。第一次调试前从头到尾看一遍；之后哪里不明白，回来查这一页。

## 1. 先认清几个名词 {#terms}

| 名词 | 是什么 |
|---|---|
| 打印头（工具头） | 装在 XY 运动机构上、跟着走的那部分：挤出机、风扇、涡流探针、CAN 板。**多头机型里它不换** |
| 热端 | 喷嘴 + 加热块 + 加热棒 + 热敏，多头机型里是可以换下来的那部分。T0、T1… 指的就是第几个热端 |
| 停靠坞（坞） | 热端不用时挂的地方，在热床前方，Y 是负数 |
| 加热棒 / 热敏 | 加热棒负责发热，热敏负责测温。两根线都接在多热端扩展板上：T1 的加热棒接 `T1H` 口，热敏接 `T1S` 口 |
| 宏 | 写在配置文件里的一组命令，起个名字就能调用，比如 `PRINT_START`、`DOCK_TUNE` |
| 配置文件 | 打印机上 `~/printer_data/config/` 里的 `.cfg` 文件。本仓库的 `config/` 目录就是它的副本 |

不知道某个宏是干什么的：在控制台输入 `MACRO_HELP`，会按分类列出所有宏和说明。

## 2. 命令在哪里输入 {#commands}

调试时要输入的命令分两种，**输入的地方不一样**：

| 命令长什么样 | 在哪里输入 | 例子 |
|---|---|---|
| G-code 和宏：大写字母开头 | 网页上的**控制台**（Mainsail / Fluidd 仪表盘里的"控制台"面板） | `G28`、`G0 X100 F3000`、`DOCK_TUNE TOOL=0` |
| Linux 命令：小写，常带 `~/` 路径 | 打印机的 **SSH 终端** | `grep ... ~/printer_data/logs/klippy.log`、`ls`、`sudo systemctl restart klipper` |

在控制台里输入 Linux 命令会报 `Unknown command:"GREP -"` 这样的错，不会有任何效果。

### 控制台

- 一行一条命令。文档里的代码块可以整段复制、一次粘贴进去，会按顺序逐行执行。
- 行里 `;` 后面是注释，打印机不会执行，可以一起复制。
- 命令写的是 `{D}`、`<打印机IP>` 这种带括号的占位符时，要先换成实际数字再发，括号也去掉。
- 发出去以后，控制台会显示打印机的回复。`//` 开头的是提示信息，`!!` 开头的是报错。

### SSH

SSH 是用电脑远程登录打印机的 Linux 系统。在 Windows 上打开 PowerShell，输入：

```
ssh klipper@<打印机IP>
```

第一次连接会问是否信任，输入 `yes` 回车；再输入密码（输入时屏幕上不显示字符，这是正常的）。看到 `klipper@...:~$` 就登录成功了。打印机 IP 在路由器的设备列表里查，或者看网页地址栏。

## 3. 急停 {#estop}

**手要一直放在急停按钮附近**，尤其是第一次跑换头、归位、加热时。

- 网页上的**紧急停止**按钮（Mainsail 在顶部栏，红色），或者在控制台输入 `M112`。
- 急停不排队，会立刻切断电机和加热。
- 急停以后打印机处于停机状态，要输入 `FIRMWARE_RESTART` 才能恢复，然后重新 `G28` 归位。

什么时候按：听到撞击声、电机发出"咯咯咯"的丢步声、看到打印头要撞上东西、闻到焦味、温度一直往上冲。宁可多按，不要犹豫。

## 4. 改配置和重启 {#config}

### 改配置的两种方式

1. **网页编辑**：Mainsail 左侧"机器"页面（Fluidd 是"配置"页面）→ 点开文件 → 修改 → 点"保存并重启"。改完会自动重启，最方便。
2. **从本仓库复制**：在电脑上改 `config/` 里的文件，再复制到打印机，见 [部署配置](./install/deploy)。复制过去以后**要手动重启**。

文档里说"第 52 行"时，网页编辑器左边有行号；行号可能因为版本不同而有出入，以参数名为准，比如找 `variable_t1_dock_x`。

### 三种重启

| 命令 | 什么时候用 |
|---|---|
| `RESTART` | 改了宏、宏里的变量（比如 `dock_x`、速度）、一般参数 |
| `FIRMWARE_RESTART` | 改了 `[mcu]`、`[extruder]`、引脚这类硬件设置；或者打印机报错停机（`Printer is shutdown`）、按过急停之后 |
| `sudo systemctl restart klipper`（SSH 里执行） | 改了 Klipper 插件的 `.py` 文件 |

不确定用哪个时，用 `FIRMWARE_RESTART`，它包含了 `RESTART` 做的事。

### 三种"保存"

| 方式 | 保存什么 | 要不要手动操作 |
|---|---|---|
| 改配置文件 | 你手动改的参数 | 改完重启即可 |
| `SAVE_CONFIG` | 涡流曲线、tap 阈值、网床、振动补偿、Z 偏移等校准结果，写到 `printer.cfg` 底部 | 校准后手动执行，会自动重启。**打印中不要执行** |
| `SAVE_VARIABLE` | 对刀偏移、当前工具、换头次数等，写到 `myvariables.cfg` | 宏自动做，**不用管** |

PID 这类写在 `modules/` 文件里的参数不能用 `SAVE_CONFIG`，会报 `conflicts with included value`，要手动填进文件。

## 5. 看懂移动命令 {#moves}

调试停靠坞时要手动发很多移动命令，先看懂它们：

| 命令 | 意思 |
|---|---|
| `G28` | 归位。X、Y、Z 都回到原点，让打印机知道自己在哪。开机后、撞过以后都要先做 |
| `G28 X Y` | 只归位 X 和 Y |
| `G90` | 后面的坐标是**绝对坐标**：`G0 X100` 表示走到 X=100 的位置 |
| `G91` | 后面的坐标是**相对坐标**：`G0 X-0.5` 表示从当前位置往 X- 走 0.5 mm |
| `G0 X282.85 Y2.1 F3000` | 走到 X=282.85、Y=2.1，速度 F3000 |
| `F` 后面的数 | 速度，单位是**毫米每分钟**。F3000 = 每秒 50 mm，F200 = 每秒约 3.3 mm（很慢，适合靠近坞时用） |
| `GET_POSITION` | 显示当前位置，看 `toolhead:` 那一行 |
| `SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0` | 清掉对刀偏移。手动量坐标前要先执行，否则量到的数会带上偏移 |

::: warning G91 之后一定要切回 G90
`G91` 会一直生效，直到发 `G90`。如果用 `G91` 走完小步、忘了切回 `G90`，下一条 `G0 X282.85` 会让打印头**再往前走 282.85 mm**，直接撞到头。文档里每段小步移动结束后都写了 `G90`，照抄就行。
:::

本机的方向：

- X、Y 归位时都往正方向走：X 停在 290，Y 停在 300（后方）。
- 停靠坞在热床**前方**，所以坞的 Y 是负数（-27.9）。Y 往负数走就是往坞里推。
- X 的行程是 0～290；Y 单头是 0～300，多头放开到 -30～300（为了能走进坞）。超出会报 `Move out of range`。

网页上的打印头面板也能点按钮移动，但调坞时要精确到 0.1 mm，**用控制台发命令更可靠**。

## 6. 看温度和日志 {#logs}

- **温度曲线**：仪表盘的温度面板，每个热端一条线。加热时看线是不是在往上走，到温后是不是平稳。
- **klippy.log**：打印机所有动作和报错都记在这里，出问题时最有用。获取方式：
  - 网页下载：Mainsail 左侧"机器"页面的日志列表；Fluidd 是"配置"页面里的 `logs`。
  - SSH 里查：`~/printer_data/logs/klippy.log`。
- 求助时，把控制台的报错原文和 `klippy.log` 一起发出去，比描述现象有用得多。

## 7. 调试习惯 {#habits}

- **一次只改一个参数**，改完测一遍，记下结果，再改下一个。同时改好几个，出了问题不知道是哪个引起的。
- **先慢后快**：先用调试速度、小步移动，确认没问题再提速。
- **每一步都记下来**：数值、现象、日期。文档里每页都有"本机记录"表格，照着填。
- **加热时不要用手直接摸加热块和喷嘴**，200°C 以上会严重烫伤。判断热端热不热，手靠近感觉热量就行。
- 打印头在动的时候，手和线不要伸进运动范围。
