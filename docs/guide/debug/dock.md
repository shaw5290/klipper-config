# 停靠坞与换头动作调试

仅多头机型。参数都在 `modules/multitool/changer_cxchanger.cfg` 的 `_multitool_cfg` 里。本页按 2026-11-04 调 T0 的实际过程整理，其他坞照同样步骤做。

## 原理

CxChanger 只靠打印头的 XY 运动换头：

- **磁吸 + 麦克斯韦耦合**：热端靠 3 颗磁铁吸在打印头上，3 个圆头销落进 3 个 V 槽定位，装上去位置可重复。
- **挂钩**：热端上的 12.9 级钢杯头螺丝推进坞后卡进坞上的大孔，被坞上的磁铁吸住，热端就留在坞里。
- **摆臂**：坞上的 5×20 圆头销。打印头在坞里沿 X 横移，销子顶开挤出机摆臂、松开耗材；横移回来摆臂闭合、夹紧耗材。

所有动作都是在 `tN_dock_x/y` 这一个基准点上加减固定距离：

| 步骤 | 放回 `_release_tool` | 抓取 `_pickup_tool` |
|---|---|---|
| 1 | `X=dock_x  Y=dock_y+safe_y`，坞前安全入口 | 同左 |
| 2 | `X=dock_x  Y=dock_y`，推入，挂钩进孔 | `X=dock_x  Y=dock_y+dodge_y`，避让位 |
| 3 | `X=dock_x+shift_x  Y=dock_y`，顶开摆臂 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，顶开摆臂 |
| 4 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，后退，磁吸分离 | `X=dock_x+shift_x  Y=dock_y`，推入，磁吸结合 |
| 5 | `X=dock_x  Y=dock_y+dodge_y`，摆臂闭合 | `X=dock_x  Y=dock_y`，夹紧耗材 |
| 6 | `X=dock_x  Y=dock_y+safe_y`，退出 | 同左，带着热端退出 |

基准点偏 0.5 mm 左右就会撞，所以要一项一项单独测，不要直接点 `T0` / `UNTOOL`。

## 调试规则

- 全程**手动逐行发命令**，每一步停下来看、听、用手拉耗材。
- **一旦撞了就先归位**再继续：撞击可能丢步，坐标已经不准。
  ```
  G90
  G0 X<当前 dock_x> Y<dock_y+safe_y> F600   ; 先退出坞（已在坞外就跳过）
  G28 X Y
  SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
  ```
- 坞内看不到时，往外退 10 mm（`Y = dock_y + 10`）观察，或用手机伸进去拍。
- 撞过几次后用手扳一下坞，确认没被撞松、撞歪。

## 准备

1. 所有热端放回坞里，打印头上不挂热端。
2. 归位并清掉对刀偏移（偏移没清，测出来的就不是机械坐标）：
   ```
   G28
   SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
   ```
3. 手动把要调的热端装到打印头上，晃一下确认没有虚位。
4. `changer_cxchanger.cfg` 用调试速度（`feed_safe 3000`、`feed_fast 600`、`feed_slow 200`），正常速度那三行保持注释。

下面以 T0 为例，`dock_y = -27.9`、`safe_y = 30`、`dodge_y = 14`。

## 第 1 步：进坞，找 X 中心

### 1.1 先确认能不能顺滑进孔

```
G90
G0 X282.5 Y2.1 F3000
G0 X282.5 Y-27.9 F300
```

确认三点：挂钩**不用力**进了孔；耗材用手**拉不动**（摆臂还夹着）；销子在摆臂的哪一侧。

### 1.2 撞在推进的哪个位置

有撞的感觉时，先找是在推进途中哪里撞的。Y 每次走 1 mm：

```
G90
G0 X282.5 Y-18 F3000
G91
G0 Y-1 F200       ; 重复，最后一步走 0.9 到 Y-27.9，一碰到就停
```

| 第几步撞 | 说明 | 处理 |
|---|---|---|
| 前几步（挂钩刚进孔） | X 没对准 | 做 1.3 |
| 最后一两步 | Y 推太深，撞坞底 | `dock_y` 改小，比如 -27.0 |
| 中间 | 热端外壳、风扇、线碰到坞 | 看是哪里碰，改结构 |

### 1.3 左右扫 X，取中点

每次 0.25 mm，每个 X 都慢慢推进再退出：

```
G90
G0 X282.25 Y2.1 F3000
G0 X282.25 Y-27.9 F200
G0 X282.25 Y2.1 F600
```

依次换成 281.5、281.75、282.0 … 283.5，记下每个是"顺滑"还是"撞"。`tN_dock_x` 取顺滑范围的**中点**。

## 第 2 步：横移，找 dock_shift_x

推进坞后先横移到一个保守值，再 0.25 mm 一步往前走：

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-27.9 F200
G0 X280.35 Y-27.9 F200      ; 先横移 -2
G91
G0 X-0.25 F200              ; 需要时再一步一步加，最多到 -4.5
```

每走一步用手插拔一下耗材，同时听声音：

- **耗材能拔出/插入，且没有撞击声**：这就是 `dock_shift_x`。
- **先听到撞击声**：停下，归位。在坞外 10 mm 做同样横移对比：坞外不撞、坞内撞，是挂钩撞孔壁或热端撞坞体；坞外也撞，是销子硬顶摆臂边角。
- 往 X- 走时销子离摆臂越来越远：方向反了，`dock_shift_x` 改成正数。

测完回位退出：

```
G90
G0 X282.35 Y-27.9 F200
G0 X282.35 Y2.1 F600
```

## 第 3 步：放回（磁吸分离）

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-27.9 F200      ; 推入
G0 X280.35 Y-27.9 F200      ; 横移，顶开摆臂
G0 X280.35 Y-13.9 F200      ; 后退 dodge_y，磁吸分离
```

停下检查：热端留在坞里、挂得稳；后退时没有被硬拽；耗材没被拽出来。然后：

```
G0 X282.35 Y-13.9 F200      ; 摆臂闭合，横移时不能碰到坞里的热端
G0 X282.35 Y2.1 F600        ; 空着退出
```

热端没留在坞里、跟着打印头出来了：加大 `dock_dodge_y` 之前，先检查挂钩是不是 12.9 级钢螺丝（304 不锈钢吸不住）、坞上的磁铁是否装好。

## 第 4 步：抓取（磁吸结合）

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-13.9 F600      ; 避让位
G0 X280.35 Y-13.9 F200      ; 横移
G0 X280.35 Y-27.9 F200      ; 推入，磁吸结合
```

停下检查热端是否被吸上、有没有被撞歪。然后：

```
G0 X282.35 Y-27.9 F200      ; 回位，夹紧耗材
G0 X282.35 Y2.1 F600        ; 带着热端退出
```

退出后确认：热端牢牢挂在打印头上、没有虚位；耗材被夹住拉不动；全程无撞击声。

## 第 5 步：用宏连续测试，再恢复正常速度

1. 把测好的值填进 `changer_cxchanger.cfg`，同步到打印机，`RESTART`。
2. 调试速度下来回切 10 次左右：
   ```
   G28
   UNTOOL
   T0
   ```
3. 切完 `G28 X Y` 再切一次，确认位置没有漂。漂了多半是丢步：检查皮带，`multitool_plugin.cfg` 的 `accel_swap`（现在 8000）不要超过机器的 `max_accel`（5000）。
4. 稳定后注释掉调试速度三行，取消正常速度三行的注释，再连续测一遍。

## 本机记录

### T0（2026-11-04）

| 参数 | 原值 | 修正后 | 依据 |
|---|---|---|---|
| `t0_dock_x` | 282.50 | **282.35**（暂定） | 282.5 进坞有撞的感觉；282.0 当时顺滑，但撞过几次后需往 X+ 挪，最终 282.35 顺滑 |
| `t0_dock_y` | -27.90 | -27.90 | 挂钩不用力进孔 |
| `dock_shift_x` | -3 | **-2** | 横移 -2 耗材已能拔出且无撞击；-3 会撞 |
| `dock_dodge_y` | 14 | 14 | 放回时热端留在坞里，抓取时正常带出 |
| 速度 | 15000 / 1200 / 400 | 调试 3000 / 600 / 200 | 正常速度保留为注释 |

过程中的现象：

- 原来 `dock_x 282.5`、`dock_shift_x -3` 时摆臂顶不开；从 282.5 横移到 -4 能松开耗材，但有撞击声。从 282.0 横移 -3 也会撞。改到 282.35、横移 -2 后，既能松开耗材，也没有撞击。
- 进坞的 X 余量只有约 ±0.5 mm（281.5、282.5 都撞），撞几次后中心就会变。余量这么小，后面容易再撞，可以考虑把坞上的大孔扩一点或给入口加倒角。

### 待办

- T1～T8 按同样步骤实测 `tN_dock_x`。坞间距约 35 mm，但 `t2_dock_x: 224.50` 和 T1 只差 23 mm，很可能填错（按间距推算约 212.5）。
- `accel_swap` 降到 5000 以下。
