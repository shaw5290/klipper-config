# 停靠坞与换头动作调试

仅多头机型。本页按 2026-11-04 调 T0、T1 的实际过程整理，T2～T7 照同样步骤做（见[调其他头](#other-tools)）。

::: tip 第一次调试
先看 [新手必读：调试的基本操作](/guide/basics)：命令在哪里输入、怎么改配置和重启、急停在哪、移动命令怎么看。
:::

## 这一页要做什么

**目标**：让每个热端都能稳定地放进坞、再从坞里拿出来，不撞、不卡、不把热端带错。

**原理一句话**：打印头推进坞 → 往旁边挪一点把挤出机松开 → 后退，热端就留在坞里了；抓取是反过来。每个坞要测准两个 X 坐标："推进去的位置"和"挪到旁边后的位置"。

**要准备的**：

- 网页控制台能正常发命令（见[新手必读](/guide/basics#commands)），手放在急停按钮附近
- 一段耗材，从第 2 步开始要装在热端里测
- 手机：坞里面看不清时伸进去拍
- 纸和笔，或者直接填本页末尾的[记录表](#records)

**每一步做完应该是什么样**：

| 步骤 | 做什么 | 做完应该是 |
|---|---|---|
| [准备](#prep) | 归位，手动把热端装到打印头上 | 热端装上去晃一下没有松动 |
| [第 1 步](#step-1) | 推进坞，左右试几个 X | 知道 X 在哪个范围内推进去不撞 |
| [第 2 步](#step-2) | 推进去后往旁边挪 | 挪完以后耗材上下拉完全没阻力 |
| [第 3 步](#step-3) | 放回 | 打印头退出来，热端留在坞里 |
| [第 4 步](#step-4) | 抓取 | 打印头带着热端出来，耗材被夹紧 |
| [第 5 步](#step-5) | 用宏连续换 10～20 次 | 全程没有撞击、没有报错 |

每一步都是**先手动一条一条发命令、看清楚了再进下一步**。下面的"要改的参数"和"原理"是查阅用的，第一次可以先跳过，直接从[准备](#prep)开始做，用到时再回来看。

## 调试要点（2026-11-04～05 的经验）

1. **先确认归位可靠**：限位开关有杂物时，归位位置会偏，测出来的坐标全部作废。调坞前 `QUERY_ENDSTOPS` 检查限位开关，连续 `G28 X Y` 几次，`GET_POSITION` 的 `mcu:` 数值要一致。
2. **按顺序、一次调一个量**：进坞 X → 横移（松开耗材）→ 后退（磁吸分离）→ 抓取。
3. **进坞 X 要扫出两边边界取中点**：可用范围只有约 ±0.5 mm，只找到一个能进的点，可能正贴着边界。
4. **横移必须装着耗材测，每走一步都停下来确认**：横移空间很窄（T0：-3 刚好，-3.25 撞），连发几步就会走过头。
5. **撞了先 `G28 X Y`** 再继续。
6. **热端一调整，这个头就要重测**；改了共用的 `dock_shift_x`，所有头都要重新确认。
7. **不要直接调用 `MULTITOOL_PICKUP_TOOL` 这类钩子宏**，换头用 `T0` / `T1` / `UNTOOL`。

## 调试弹窗（推荐） {#tune}

```
G28 X Y
DOCK_TUNE TOOL=0
```

网页上会弹出"停靠坞调试 T0"对话框（需要 Mainsail 2.9 及以上，或较新版本的 Fluidd），显示当前的进坞 X、横移量、累计横移和记录的松开点 / 撞击点。每按一次按钮，打印头动一步、对话框刷新数值。

| 按钮 | 作用 | 出现的时候 |
|---|---|---|
| X -1 / -0.5 / -0.1 / -0.01，X +0.01 / +0.1 / +0.5 / +1 | 进坞 X 临时改这么多，退出后重新推进（扫进坞 X） | 一直有 |
| 横移 -1 … -0.01，横移 +0.01 … +1 | 在坞里横移一步（累计上限 6 mm，不能和 `dock_shift_x` 反向） | 在坞里 |
| 横移到 -3.00 | 直接横移到当前的 `dock_shift_x` | 在坞里 |
| 记为松开点 / 记为撞击点 | 把当前横移后的 X 记下来 | 在坞里 |
| 后退 +0.01 … +1，后退 -1 … -0.01 | 往外后退 / 往回推，看热端是否留在坞里 | 在坞里 |
| 后退到 14.00 | 直接后退到当前的 `dock_dodge_y` | 在坞里 |
| 退出坞 | 摆臂闭合，退到坞前 | 在坞里 |
| 进坞 / 抓取测试 | 推进坞停在里面 / 按当前参数抓取，停在推入那一步 | 在坞外 |
| 按中点更新进坞 X | 进坞 X = (松开点 + 撞击点) / 2 - 横移量 | 在坞外，且两个点都记了 |
| 显示结果 | 在控制台打印要写进文件的值 | 底部 |
| 关闭 | 关掉对话框 | 底部 |

步距怎么选：先用 1 或 0.5 快速靠近，接近边界时换 0.1，最后用 0.01 微调。横移找撞击点时**不要用 1**，一下走太多。

找横移阈值的流程（横移量 -3 固定，按中点反推进坞 X）：

1. 点"进坞"，再点几次"横移 -0.15"，横移到耗材还有一点阻力的位置（比如累计 -2.4）。
2. 继续一下一下点"横移 -0.15"，每点一次拉一下耗材；第一次完全没阻力时点"记为松开点"。
3. 继续"横移 -0.15"，**一听到撞击声**就点"记为撞击点"，再点"退出坞"，然后在控制台 `G28 X Y`。
4. 点"按中点更新进坞 X"，再"进坞"→"横移到 -3.00"→"后退到 14.0"→"退出坞"→"抓取测试"→"退出坞"，确认放回、抓取都正常。
5. 保存，见下面。

### 调好以后怎么保存 {#save}

弹窗和 `DOCK_SET` 改的值只在内存里，`RESTART` 或断电后会恢复成文件里的值，**必须写进文件**：

1. 点弹窗底部的"显示结果"，控制台会打印类似：
   `DOCK_TUNE 结果：把 changer_cxchanger.cfg 里 variable_t0_dock_x 改成 282.78，variable_dock_shift_x 是 -3.00，variable_dock_dodge_y 是 14.00；改完 RESTART`
2. 打开 `changer_cxchanger.cfg`（Mainsail 左侧"机器"页面 → `modules/multitool/changer_cxchanger.cfg`），找到 `[gcode_macro _multitool_cfg]` 里对应的行，改成控制台显示的数：
   ```
   variable_t0_dock_x: 282.78
   ```
   横移、后退调过的话，`variable_dock_shift_x`、`variable_dock_dodge_y` 也一起改。
3. 点"保存并重启"。重启后执行 `DOCK_SHOW`，确认显示的就是新值。
4. 如果平时在电脑上改仓库里的 `config/`，再把同样的改动写回仓库，免得下次同步时被旧值覆盖。

弹窗里改的值都是临时的（同 `DOCK_SET`），`RESTART` 后恢复成文件里的值。撞得重时不要点按钮，直接按急停，见[调试规则](#rules)。

## 快速调试宏 {#macros}

下面每一步的手动命令都可以换成 `DOCK_` 宏（在 `changer_cxchanger.cfg` 末尾）：坐标从配置自动算，全程绝对坐标（不会有 `G91` 忘切回的问题），横移有上限保护，改参数不用重启。

| 宏 | 作用 | 对应步骤 |
|---|---|---|
| `DOCK_SHOW` | 列出各坞的进坞 X、横移后 X、横移、后退 | 随时 |
| `DOCK_GO TOOL=0` | 推进 T0 的坞并停在里面 | 第 1 步 |
| `DOCK_GO TOOL=0 DX=-0.25` | 在 `dock_x - 0.25` 处推进（扫 X 用） | 第 1 步 1.3 |
| `DOCK_SHIFT` | 在坞里再横移 -0.25（累计）；累计超过 \|dock_shift_x\|+0.5 会拒绝 | 第 2 步 |
| `DOCK_SHIFT TO=-3` | 直接横移到累计 -3 | 第 2 步 |
| `DOCK_BACK` | 往外后退 2 mm（累计），看热端何时分开 | 第 3 步 |
| `DOCK_BACK TO=14` | 直接后退到 14 | 第 3 步 |
| `DOCK_PICKUP TOOL=0` | 按当前参数抓取，停在"推入、磁吸结合" | 第 4 步 |
| `DOCK_OUT` | X 回进坞位置（摆臂闭合），再退到坞前 | 每次看完 |
| `DOCK_SET TOOL=0 X=283.65` | 临时改参数，立即生效，`TOOLCHANGE_TEST` 也会用新值 | 测完 |
| `DOCK_SET SHIFT=-3` / `DOCK_SET DODGE=14` | 临时改共用的横移 / 后退 | 测完 |

一个头的完整流程（以 T0 为例）：

```
G28 X Y
DOCK_SHOW
DOCK_GO TOOL=0                 ; 第 1 步：顺滑吗？偏左偏右？
DOCK_OUT
DOCK_GO TOOL=0 DX=-0.25        ; 偏右就往 X- 扫，偏左用正数
DOCK_OUT
DOCK_SET TOOL=0 X=283.65       ; 找到中点后临时生效
DOCK_GO TOOL=0                 ; 第 2 步：装着耗材
DOCK_SHIFT TO=-2               ; 先横移 -2，拉耗材
DOCK_SHIFT                     ; 还有阻力就每次 -0.25，一次一条，每条都拉耗材、听声音
DOCK_BACK TO=14                ; 第 3 步：热端应留在坞里
DOCK_OUT
DOCK_PICKUP TOOL=0             ; 第 4 步：热端吸上了吗
DOCK_OUT                       ; 夹紧并带出
TOOLCHANGE_TEST TOOL=0 COUNT=5 WAIT=2   ; 第 5 步
```

全部通过后，把 `DOCK_SET` 改过的值写进 `changer_cxchanger.cfg`（`RESTART` 后临时值会恢复成文件里的值）。

注意：

- 打印头上装的热端要和 `TOOL` 一致。
- 还停在坞里（没 `DOCK_OUT`）或打印头在坞附近时，`DOCK_GO` / `DOCK_PICKUP` 会拒绝执行，先退到坞前安全入口。
- 这些宏不经过换头插件，插件记录的当前工具不会变。用 `DOCK_BACK` 把热端放进坞以后，要用 `DOCK_PICKUP` + `DOCK_OUT` 拿回来，保持和插件记录一致。

## 要改的参数

换头动作的参数都在 **`config/modules/multitool/changer_cxchanger.cfg`** 的 `[gcode_macro _multitool_cfg]` 里。行号是 2026-11-04 的版本，以文件实际内容为准。

| 参数 | 行号 | 管什么 | 用哪一步测 | 范围 | 当前值 |
|---|---|---|---|---|---|
| `variable_tN_dock_x` | 50、52、54…66 | 第 N 个坞的进坞 X（挂钩对准大孔） | [第 1 步](#step-1)、[第 2 步](#step-2) | **每个头单独测** | T0 = 283.65，T1 = 248.30（热端调整后待重新确认） |
| `variable_tN_dock_y` | 51、53、55…67 | 第 N 个坞的推入深度 | [第 1 步](#step-1) 的 1.2 | 每个头确认，一般相同 | -27.90 |
| `variable_dock_shift_x` | 45 | 推入后 X 横移多少，顶开摆臂 | [第 2 步](#step-2)（**必须装着耗材测**） | 所有头共用 | **-3** |
| `variable_dock_dodge_y` | 46 | 后退多少，让磁吸分离 | [第 3 步](#step-3) | 所有头共用 | 14 |
| `variable_dock_safe_y` | 47 | 坞前安全入口离坞多远 | 一般不用改 | 所有头共用 | 30 |
| `variable_feed_safe/fast/slow` | 36～38（调试）、40～42（正常） | 换头速度 | [第 5 步](#step-5) | 所有头共用 | 调试 3000 / 600 / 200 |

其他文件里相关的参数：

| 文件 | 参数 | 什么时候改 |
|---|---|---|
| `config/modules/multitool/multitool_plugin.cfg` 第 38 行 | `tool_count` | 启用更多头时（见[调其他头](#other-tools)） |
| `config/modules/multitool/multitool_plugin.cfg` 第 43 行 | `accel_swap` | 现在 8000，超过机器 `max_accel` 5000，建议改成 5000 |
| `config/profile_multitool.cfg` 第 40 行 | `[stepper_y] position_min` | `dock_y` 改得更深时，要比最深的 `dock_y` 再小 3～5 mm |

**改完任何参数**：把文件同步到打印机 `~/printer_data/config/`，执行 `RESTART`（网页编辑器里点"保存并重启"会自动重启）。手动逐行测试时用的是命令里写死的坐标，不需要重启；用 `T0` / `UNTOOL` / `TOOLCHANGE_TEST` 测试前才要先改参数、重启。

## 原理

CxChanger 只靠打印头的 XY 运动换头：

- **磁吸 + 麦克斯韦耦合**：热端靠 3 颗磁铁吸在打印头上，3 个圆头销落进 3 个 V 槽定位，装上去位置可重复。
- **挂钩**：热端上的 12.9 级钢杯头螺丝推进坞后卡进坞上的大孔，被坞上的磁铁吸住，热端就留在坞里。
- **摆臂**：坞上的 5×20 圆头销。打印头在坞里沿 X 横移，销子顶开挤出机摆臂、松开耗材；横移回来摆臂闭合、夹紧耗材。

宏里的每个动作都是在 `tN_dock_x/y` 上加减固定距离：

| 步骤 | 放回 `_release_tool` | 抓取 `_pickup_tool` |
|---|---|---|
| 1 | `X=dock_x  Y=dock_y+safe_y`，坞前安全入口 | 同左 |
| 2 | `X=dock_x  Y=dock_y`，推入，挂钩进孔 | `X=dock_x  Y=dock_y+dodge_y`，避让位 |
| 3 | `X=dock_x+shift_x  Y=dock_y`，顶开摆臂 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，顶开摆臂 |
| 4 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，后退，磁吸分离 | `X=dock_x+shift_x  Y=dock_y`，推入，磁吸结合 |
| 5 | `X=dock_x  Y=dock_y+dodge_y`，摆臂闭合 | `X=dock_x  Y=dock_y`，夹紧耗材 |
| 6 | `X=dock_x  Y=dock_y+safe_y`，退出 | 同左，带着热端退出 |

所以每个头有**两个 X 位置都要对**：

| 位置 | X | 要求 |
|---|---|---|
| 进坞 X | `dock_x` | 挂钩顺滑进孔，不撞 |
| 横移后 X | `dock_x + dock_shift_x` | 装着耗材时，耗材上下拉**完全没有阻力** |

按当前值，所有坞的 Y 坐标是固定的三个：

| 位置 | 计算 | Y |
|---|---|---|
| 安全入口 | -27.9 + 30 | **2.1** |
| 避让位 | -27.9 + 14 | **-13.9** |
| 坞内 | `dock_y` | **-27.9** |

基准点偏 0.5 mm 左右就会撞，所以要一项一项单独测，不要直接点 `T0` / `UNTOOL`。

## 调试规则 {#rules}

- 全程**手动逐行发命令**，每一步停下来看、听、用手拉耗材。
- 从第 2 步开始**必须装着耗材测**。不装耗材时"能拉动"不代表齿轮完全松开，装上耗材后放回时会被齿轮拖着走，热端留不进坞里。
- **一旦撞了就先归位**再继续：撞击可能丢步，坐标已经不准。
  ```
  G90
  G0 X<这个头的 dock_x> Y2.1 F600   ; 先退出坞（已在坞外就跳过）
  G28 X Y
  SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
  ```
- 坞内看不到时，往外退 10 mm（Y-17.9）观察，或用手机伸进去拍。
- 撞过几次后用手扳一下坞，确认没被撞松、撞歪。
- 发命令前核对 X：一次把 `G0 X248.5 Y2.1` 后面接成了 `G0 X247.5 Y-27.9`，打印头会斜着进坞。

## 准备 {#prep}

1. 所有热端放回坞里，打印头上不挂热端。
2. 归位并清掉对刀偏移（偏移没清，测出来的就不是机械坐标）：
   ```
   G28
   SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
   ```
3. 手动把要调的热端装到打印头上，晃一下确认没有虚位。

下面的命令以 T0 为例（`dock_x = 283.65`，横移后 `280.65`）。调其他头时，把 X 换成[坐标表](#coords)里对应的值，Y 不变。

## 第 1 步：进坞，找进坞 X 的范围 {#step-1}

**这一步决定：`variable_tN_dock_x` 能取的范围，必要时 `variable_tN_dock_y`。**

### 1.1 先确认能不能顺滑进孔

```
G90
G0 X283.65 Y2.1 F3000
G0 X283.65 Y-27.9 F300
G0 X283.65 Y2.1 F600
```

确认：挂钩**不用力**进了孔；有撞的感觉时，记下感觉是往左还是往右偏。

### 1.2 撞在推进的哪个位置

有撞的感觉时，先找是在推进途中哪里撞的。Y 每次走 1 mm：

```
G90
G0 X283.65 Y-18 F3000
G91
G0 Y-1 F200       ; 重复，最后一步走 0.9 到 Y-27.9，一碰到就停
```

| 第几步撞 | 说明 | 改什么 |
|---|---|---|
| 前几步（挂钩刚进孔） | X 没对准 | 做 1.3 |
| 最后一两步 | Y 推太深，撞坞底 | 把 `variable_tN_dock_y` 改大一点（往 0 靠），比如 -27.90 改成 -27.00 |
| 中间 | 热端外壳、风扇、线碰到坞 | 参数解决不了，要看是哪里碰，改结构 |

### 1.3 左右扫 X，找顺滑范围

每次 0.25 mm，每个 X 都慢慢推进再退出：

```
G90
G0 X283.4 Y2.1 F3000
G0 X283.4 Y-27.9 F200
G0 X283.4 Y2.1 F600
```

把三行里的 X 依次换成 当前值-0.75、-0.5、-0.25、0、+0.25、+0.5、+0.75，往两边扫到开始撞为止，记下每个是"顺滑"还是"撞"。

**记下顺滑范围**（比如 T1 是 247.5～248.5 都能进），第 2 步要用。先暂时填中点。

## 第 2 步：找横移后 X，定 dock_x 和 dock_shift_x {#step-2}

**这一步决定：`variable_dock_shift_x`（第 45 行，所有头共用），以及每个头最终的 `variable_tN_dock_x`。**

::: warning 必须装着耗材测
判断标准是**耗材上下拉完全没有阻力**（齿轮完全离开耗材），不是"能拉动"。

本机 T0 第一次测时没装耗材，横移 -2 耗材能拉动，就定了 -2；装上耗材后放回，挤出机还夹着耗材，打印头后退时把热端一起带了出来。
:::

### 2.1 找耗材完全松开的 X

装上耗材，推进坞后先横移到当前的 `dock_shift_x`，再每次多走 0.1 mm：

```
G28 X Y
G90
G0 X283.65 Y2.1 F3000
G0 X283.65 Y-27.9 F200
```

### 2.2 两种改法

`dock_shift_x` 是所有头共用的，每个头都要满足"`dock_x` 在进坞顺滑范围内"和"`dock_x + dock_shift_x` ≤ 松开 X"（往 X- 横移时）。

| 改法 | 怎么改 | 适用 |
|---|---|---|
| **只改这个头的 `dock_x`**（`dock_shift_x` 不动） | `tN_dock_x` = 松开 X - `dock_shift_x` - 0.1（多 0.1 余量）。例如松开 X = 245.9、shift = -2：`dock_x` = 245.9 + 2 - 0.1 = 247.8 | 算出来的 `dock_x` 还在第 1 步的顺滑范围内 |
| **同时改 `dock_shift_x` 和所有 `dock_x`** | `dock_shift_x` 加大 a，所有 `tN_dock_x` 加 a：横移后 X 不变，进坞 X 往外挪 a | 只改 `dock_x` 会让进坞偏到顺滑范围的边上 |

## 第 5 步：用宏连续测试，再恢复正常速度 {#step-5}

**这一步改：速度（第 36～42 行）、`accel_swap`（`multitool_plugin.cfg` 第 43 行）。**

1. 确认第 1～3 步测出的值都已填进 `changer_cxchanger.cfg`，同步到打印机，`RESTART`。
2. 装着耗材，调试速度下用 `TOOLCHANGE_TEST` 反复取放（宏在 `multitool_plugin.cfg` 末尾）：
   ```
   TOOLCHANGE_TEST TOOL=0 COUNT=10 WAIT=2
   ```
   T0 抓取 → 放回，重复 10 次，每次换头后停 2 秒，方便观察。控制台会显示"第 3/10 次"这样的进度，出错（撞、超出行程）会立即停止。宏发现不了"热端没留在坞里"这类不报错的问题，人要在旁边看，不对马上点急停。
3. 检查是否丢步：每 5 次重新归位一次 XY，归位后还能正常取放，说明位置没有漂：
   ```
   TOOLCHANGE_TEST TOOL=0 COUNT=20 REHOME=5
   ```
   归位后第一次就撞或者越来越偏，多半是丢步：检查皮带，把 `accel_swap` 改成 5000。
4. 稳定后切到正常速度：第 36～38 行行首加 `#`，第 40～42 行删掉行首的 `#`，`RESTART`，再测一遍：
   ```
   TOOLCHANGE_TEST TOOL=0 COUNT=20 REHOME=5
   ```
5. 调好两个以上的头后，测打印时那样的直接换头（中间不放空）：
   ```
   TOOLCHANGE_TEST TOOLS=0,1 COUNT=10
   ```

`TOOLCHANGE_TEST` 参数：

| 参数 | 默认 | 说明 |
|---|---|---|
| `TOOL` | 0（T0） | 单个工具：每次抓取 → 放回 |
| `TOOLS` | — | 多个工具，逗号分隔，比如 `0,1`：每轮按顺序依次换头，中间不放空；给了 `TOOLS` 就不看 `TOOL` |
| `COUNT` | 5 | 次数（用 `TOOLS` 时是轮数），1～100 |
| `REHOME` | 0 | 每多少次重新归位 XY，0 = 不归位 |
| `WAIT` | 0 | 每次换头后停顿的秒数 |
| `KEEP` | 0 | 1 = 结束时保留最后一个工具在打印头上；0 = 结束时放回（`UNTOOL`） |

开始前打印头上有热端时，宏会先 `UNTOOL` 放回；没有归位时会先 `G28`。工具号超出 `tool_count`、或 `COUNT` 不在 1～100 时直接报错，不动作。
