# 停靠坞与换头动作调试

仅多头机型。本页按 2026-11-04 调 T0 的实际过程整理，T1～T7 照同样步骤做（见文末[调其他头](#other-tools)）。

## 要改的参数

换头动作的参数都在 **`config/modules/multitool/changer_cxchanger.cfg`** 的 `[gcode_macro _multitool_cfg]` 里。行号是 2026-11-04 的版本，以文件实际内容为准。

| 参数 | 行号 | 管什么 | 用哪一步测 | 范围 | 当前值 |
|---|---|---|---|---|---|
| `variable_tN_dock_x` | 50、52、54…66 | 第 N 个坞的 X 中心（挂钩对准大孔） | [第 1 步](#step-1) | **每个头单独测** | T0 = 282.35 |
| `variable_tN_dock_y` | 51、53、55…67 | 第 N 个坞的推入深度 | [第 1 步](#step-1) 的 1.2 | 每个头确认，一般相同 | -27.90 |
| `variable_dock_shift_x` | 45 | 推入后 X 横移多少，顶开摆臂 | [第 2 步](#step-2) | 所有头共用 | -2 |
| `variable_dock_dodge_y` | 46 | 后退多少，让磁吸分离 | [第 3 步](#step-3) | 所有头共用 | 14 |
| `variable_dock_safe_y` | 47 | 坞前安全入口离坞多远 | 一般不用改 | 所有头共用 | 30 |
| `variable_feed_safe/fast/slow` | 36～38（调试）、40～42（正常） | 换头速度 | [第 5 步](#step-5) | 所有头共用 | 调试 3000 / 600 / 200 |

其他文件里相关的参数：

| 文件 | 参数 | 什么时候改 |
|---|---|---|
| `config/modules/multitool/multitool_plugin.cfg` 第 38 行 | `tool_count` | 启用更多头时（见[调其他头](#other-tools)） |
| `config/modules/multitool/multitool_plugin.cfg` 第 43 行 | `accel_swap` | 现在 8000，超过机器 `max_accel` 5000，建议改成 5000 |
| `config/profile_multitool.cfg` 第 40 行 | `[stepper_y] position_min` | `dock_y` 改得更深时，要比最深的 `dock_y` 再小 3～5 mm |

**改完任何参数**：把文件同步到打印机 `~/printer_data/config/`，执行 `RESTART`。手动逐行测试时用的是命令里写死的坐标，不需要重启；只有用 `T0` / `UNTOOL` 宏测试时才要先改参数、重启。

## 原理

CxChanger 只靠打印头的 XY 运动换头：

- **磁吸 + 麦克斯韦耦合**：热端靠 3 颗磁铁吸在打印头上，3 个圆头销落进 3 个 V 槽定位，装上去位置可重复。
- **挂钩**：热端上的 12.9 级钢杯头螺丝推进坞后卡进坞上的大孔，被坞上的磁铁吸住，热端就留在坞里。
- **摆臂**：坞上的 5×20 圆头销。打印头在坞里沿 X 横移，销子顶开挤出机摆臂、松开耗材；横移回来摆臂闭合、夹紧耗材。

宏里的每个动作都是在 `tN_dock_x/y` 上加减固定距离：

| 步骤 | 放回 `_release_tool` | 抓取 `_pickup_tool` |
|---|---|---|
| 1 | `X=dock_x  Y=dock_y+safe_y`，坞前安全入口 | 同左 |
| 2 | `X=dock_x  Y=dock_y`，推入，挂钩进孔 | `X=dock_x  Y=dock_y+dodge_y`，避让位 |
| 3 | `X=dock_x+shift_x  Y=dock_y`，顶开摆臂 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，顶开摆臂 |
| 4 | `X=dock_x+shift_x  Y=dock_y+dodge_y`，后退，磁吸分离 | `X=dock_x+shift_x  Y=dock_y`，推入，磁吸结合 |
| 5 | `X=dock_x  Y=dock_y+dodge_y`，摆臂闭合 | `X=dock_x  Y=dock_y`，夹紧耗材 |
| 6 | `X=dock_x  Y=dock_y+safe_y`，退出 | 同左，带着热端退出 |

按当前值，所有坞的 Y 坐标是固定的三个：

| 位置 | 计算 | Y |
|---|---|---|
| 安全入口 | -27.9 + 30 | **2.1** |
| 避让位 | -27.9 + 14 | **-13.9** |
| 坞内 | `dock_y` | **-27.9** |

基准点偏 0.5 mm 左右就会撞，所以要一项一项单独测，不要直接点 `T0` / `UNTOOL`。

## 调试规则

- 全程**手动逐行发命令**，每一步停下来看、听、用手拉耗材。
- **一旦撞了就先归位**再继续：撞击可能丢步，坐标已经不准。
  ```
  G90
  G0 X<这个头的 dock_x> Y2.1 F600   ; 先退出坞（已在坞外就跳过）
  G28 X Y
  SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
  ```
- 坞内看不到时，往外退 10 mm（Y-17.9）观察，或用手机伸进去拍。
- 撞过几次后用手扳一下坞，确认没被撞松、撞歪。

## 准备

1. 所有热端放回坞里，打印头上不挂热端。
2. 归位并清掉对刀偏移（偏移没清，测出来的就不是机械坐标）：
   ```
   G28
   SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0
   ```
3. 手动把要调的热端装到打印头上，晃一下确认没有虚位。

下面的命令以 T0 为例（`dock_x = 282.35`，横移后 `280.35`）。调其他头时，把 X 换成[坐标表](#coords)里对应的值，Y 不变。

## 第 1 步：进坞，找 X 中心 {#step-1}

**这一步决定：`variable_tN_dock_x`（必测），必要时 `variable_tN_dock_y`。**

### 1.1 先确认能不能顺滑进孔

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-27.9 F300
```

确认三点：挂钩**不用力**进了孔；耗材用手**拉不动**（摆臂还夹着）；销子在摆臂的哪一侧。

### 1.2 撞在推进的哪个位置

有撞的感觉时，先找是在推进途中哪里撞的。Y 每次走 1 mm：

```
G90
G0 X282.35 Y-18 F3000
G91
G0 Y-1 F200       ; 重复，最后一步走 0.9 到 Y-27.9，一碰到就停
```

| 第几步撞 | 说明 | 改什么 |
|---|---|---|
| 前几步（挂钩刚进孔） | X 没对准 | 做 1.3，改 `variable_tN_dock_x` |
| 最后一两步 | Y 推太深，撞坞底 | 把 `variable_tN_dock_y` 改大一点（往 0 靠），比如 -27.90 改成 -27.00 |
| 中间 | 热端外壳、风扇、线碰到坞 | 参数解决不了，要看是哪里碰，改结构 |

### 1.3 左右扫 X，取中点

每次 0.25 mm，每个 X 都慢慢推进再退出：

```
G90
G0 X282.25 Y2.1 F3000
G0 X282.25 Y-27.9 F200
G0 X282.25 Y2.1 F600
```

把三行里的 X 依次换成 当前值-0.75、-0.5、-0.25、0、+0.25、+0.5、+0.75（T0 就是 281.6 ～ 283.1），记下每个是"顺滑"还是"撞"。

**测完改**：`variable_tN_dock_x` = 顺滑范围的**中点**。例如 282.0～282.7 都顺滑，就填 282.35。

## 第 2 步：横移，找 dock_shift_x {#step-2}

**这一步决定：`variable_dock_shift_x`（第 45 行，所有头共用）。T1 以后只需要用当前值确认一下，不用重新找。**

推进坞后先横移 -2，再 0.25 mm 一步往前走：

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-27.9 F200
G0 X280.35 Y-27.9 F200      ; 横移 -2（X = dock_x - 2）
G91
G0 X-0.25 F200              ; 需要时再一步一步加，最多累计到 -4.5
```

每走一步用手插拔一下耗材，同时听声音：

| 现象 | 改什么 |
|---|---|
| 耗材能拔出/插入，且没有撞击声 | `variable_dock_shift_x` = 这时的累计横移量（负数），比如走到 -2.25 才松开就填 -2.25 |
| 先听到撞击声 | 先不改。停下、归位，在坞外（Y-17.9）做同样横移对比：坞外不撞、坞内撞 → 挂钩撞孔壁或热端撞坞体，先回第 1 步重找 `dock_x`；坞外也撞 → 销子硬顶摆臂边角，要调销子，参数解决不了 |
| 往 X- 走时销子离摆臂越来越远 | 方向反了：`variable_dock_shift_x` 改成正数（比如 2），用 `G0 X0.25` 重测 |

测完回位退出：

```
G90
G0 X282.35 Y-27.9 F200
G0 X282.35 Y2.1 F600
```

## 第 3 步：放回（磁吸分离） {#step-3}

**这一步确认：`variable_dock_dodge_y`（第 46 行，所有头共用）。**

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-27.9 F200      ; 推入
G0 X280.35 Y-27.9 F200      ; 横移，顶开摆臂
G0 X280.35 Y-13.9 F200      ; 后退 dodge_y（14），磁吸分离
```

停下检查：热端留在坞里、挂得稳；后退时没有被硬拽；耗材没被拽出来。然后：

```
G0 X282.35 Y-13.9 F200      ; 摆臂闭合，横移时不能碰到坞里的热端
G0 X282.35 Y2.1 F600        ; 空着退出
```

| 现象 | 改什么 |
|---|---|
| 热端留在坞里，退出无碰撞 | 不用改 |
| 热端跟着打印头出来了 | 先查挂钩是不是 12.9 级钢螺丝（304 不锈钢吸不住）、坞上的磁铁有没有装好。机械没问题再考虑加大 `variable_dock_dodge_y` |
| 回位横移时碰到坞里的热端 | 加大 `variable_dock_dodge_y`，每次加 2 |

## 第 4 步：抓取（磁吸结合） {#step-4}

**这一步不产生新参数**，用第 1～3 步的结果验证抓取。

```
G90
G0 X282.35 Y2.1 F3000
G0 X282.35 Y-13.9 F600      ; 避让位
G0 X280.35 Y-13.9 F200      ; 横移
G0 X280.35 Y-27.9 F200      ; 推入，磁吸结合
```

停下检查热端是否被吸上、有没有被撞歪。然后：

```
G0 X282.35 Y-27.9 F200      ; 回位，夹紧耗材
G0 X282.35 Y2.1 F600        ; 带着热端退出
```

退出后确认：热端牢牢挂在打印头上、没有虚位；耗材被夹住拉不动；全程无撞击声。推入时撞，回第 1 步；夹不紧，回第 2 步。

## 第 5 步：用宏连续测试，再恢复正常速度 {#step-5}

**这一步改：速度（第 36～42 行）、`accel_swap`（`multitool_plugin.cfg` 第 43 行）。**

1. 确认第 1～3 步测出的值都已填进 `changer_cxchanger.cfg`，同步到打印机，`RESTART`。
2. 调试速度下来回切 10 次左右（T1 以后把 `T0` 换成对应的 `T1`、`T2`…）：
   ```
   G28
   UNTOOL
   T0
   ```
3. 切完 `G28 X Y` 再切一次，确认位置没有漂。漂了多半是丢步：检查皮带，把 `accel_swap` 改成 5000。
4. 稳定后切到正常速度：第 36～38 行行首加 `#`，第 40～42 行删掉行首的 `#`，`RESTART`，再连续测一遍。

## 调其他头 {#other-tools}

### 启用前先改

当前只启用了 2 个头。要调 T2 以后的头，先改：

| 文件 | 改什么 |
|---|---|
| `multitool_plugin.cfg` 第 38 行 | `tool_count: 2` 改成实际装的热端数量 |
| `multihotend.cfg` | 对应的 `[extruderN]` 和 `[heater_fan dock_fan_tN]` 保持启用（没装的注释掉） |

`multihotend.cfg` 里只有 `extruder`～`extruder7`，最多 8 个头（T0～T7）。`changer_cxchanger.cfg` 里的 `t8_dock_x/y` 没有对应的热端，用不到。

### 每个头要做什么

| 步骤 | T0 | T1～T7 |
|---|---|---|
| 第 1 步（`dock_x`） | 已测 | **每个都要测**，主要是 1.3 扫 X |
| 第 1 步 1.2（`dock_y`） | 已测 | 1.1 能不用力进孔就跳过；进不去再测 |
| 第 2 步（`dock_shift_x`） | 已测 = -2 | 只用 -2 确认一次能松开耗材、不撞。某个头不行，**先回第 1 步重找 `dock_x`**，不要改共用的 `dock_shift_x` |
| 第 3、4 步 | 已测 | 每个都确认一次 |
| 第 5 步 | — | 每个头都用 `UNTOOL` / `TN` 切几次，最后混切 `T0`、`T1`、`T2`… |

建议从 T1 开始按顺序一个一个调，**调完一个、填进配置、再调下一个**。

### 例：T1 的完整命令

手动把 T1 热端装到打印头上，其他热端都在坞里。

```
; 准备
G28
SET_GCODE_OFFSET X=0 Y=0 Z=0 MOVE=0

; 1.1 进坞
G90
G0 X247.5 Y2.1 F3000
G0 X247.5 Y-27.9 F300
G0 X247.5 Y2.1 F600

; 1.3 扫 X：把三行的 247.5 依次换成 246.75、247.0、247.25、247.5、247.75、248.0、248.25
G0 X246.75 Y2.1 F3000
G0 X246.75 Y-27.9 F200
G0 X246.75 Y2.1 F600
```

测完把 `variable_t1_dock_x`（第 52 行）改成顺滑范围的中点，下面用这个新值（记作 `D`，横移后是 `D-2`）：

```
; 第 2 步：确认横移 -2 能松开耗材、不撞
G0 X{D} Y2.1 F3000
G0 X{D} Y-27.9 F200
G0 X{D-2} Y-27.9 F200        ; 插拔耗材确认
G0 X{D} Y-27.9 F200
G0 X{D} Y2.1 F600

; 第 3 步：放回
G0 X{D} Y2.1 F3000
G0 X{D} Y-27.9 F200
G0 X{D-2} Y-27.9 F200
G0 X{D-2} Y-13.9 F200        ; 热端应留在坞里
G0 X{D} Y-13.9 F200
G0 X{D} Y2.1 F600

; 第 4 步：抓取
G0 X{D} Y2.1 F3000
G0 X{D} Y-13.9 F600
G0 X{D-2} Y-13.9 F200
G0 X{D-2} Y-27.9 F200        ; 热端应被吸上
G0 X{D} Y-27.9 F200
G0 X{D} Y2.1 F600            ; 带出热端，耗材夹紧
```

`{D}` 要换成实际数字再发，比如 `D = 247.4` 时，`G0 X{D-2} Y-27.9` 就发 `G0 X245.4 Y-27.9 F200`。

然后 `RESTART`，按第 5 步用 `UNTOOL` / `T1` 连续切几次。

| 参数 | 原值 | 修正后 | 依据 |

过程中的现象：

- 原来 `dock_x 282.5`、`dock_shift_x -3` 时摆臂顶不开；从 282.5 横移到 -4 能松开耗材，但有撞击声。从 282.0 横移 -3 也会撞。改到 282.35、横移 -2 后，既能松开耗材，也没有撞击。
- 进坞的 X 余量只有约 ±0.5 mm（281.5、282.5 都撞），撞几次后中心就会变。余量这么小，后面容易再撞，可以考虑把坞上的大孔扩一点或给入口加倒角。
